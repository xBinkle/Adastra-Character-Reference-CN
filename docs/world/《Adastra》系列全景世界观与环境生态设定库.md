# 《Adastra》系列全景世界观与环境生态设定库

## 一、宇宙总纲

### 1. 一个由共同生命谱系展开的宇宙

银河中的生命并非在每颗星球上彼此独立地偶然诞生。至少在已知文明所处的这一侧宇宙，绝大多数普通生命都可追溯到同一源头。生命被播散到不同世界后，在相近的生存压力下沿着相似方向演化，因此彼此相隔数十光年乃至更远的行星，仍会重复出现树木、草本、昆虫、鸟类、鱼类和披毛哺乳动物，也会出现狼、猫、豺、狮、熊、狼獾与灵长类相似的智慧物种。它们不是地球动物简单移居后的后裔，而是共同生命基础在不同环境中的本地化分化。

这种共同性解释了诸文明之间大量看似不可思议的相似之处：多数智慧种都需要空气、水、食物与睡眠；能辨认彼此的表情、伤痛、幼体和死亡；可以共享相当一部分医学、农业和营养学知识；社会中也反复出现家庭、城市、权力、信仰、贸易、战争和艺术。相似不等于完全兼容。不同世界的病毒、药物、气压、重力和食物仍可造成致命后果，最危险的情况甚至会来自一场对其他物种极为普通的传染病。

人类所在的地球是这套共同谱系中最特殊的文明实验。地球文化同时保留了狼族、克米扬、辛多、奥莫法人及其他 Sibling 文明的深层痕迹，并在彼此不知道银河真相的情况下把这些传统混合为一个多文明缩影。人类并非等待某个外星帝国占有的普通未接触种族，也不应成为狼族或任何另一 Sibling 的附庸。其发展结果已经接近一个独立 Sibling 文明；未来的整合应由人类自己完成，并只在 Parent 层级之下进入银河共同体。

### 2. 物质宇宙与多重层面

日常世界是可由肉体、机械和常规感官活动的物质层面。其外还存在多个彼此相邻却通常互不通透的层面。意识、记忆与 Parent 的存在方式不完全受物质层面的距离和线性时间约束；少数心智具有较高的“柔韧性”，能够让知觉越过层面边界。跨层面并不等于任意施法，也不会让个体自动获得全知。它更像在一扇平日紧闭的门上打开缝隙：接触者可以感到情绪、意图、熟悉的意识或非物质空间，却可能因缺少引导而迷失、剧痛、昏厥，或把自己的愿望误认成外来讯息。

Stretch 航行会使层面之间的边界变薄。飞船进入 Stretch 时，光线发生弯曲，空间感被拉长，未经适应者会眩晕、恶心；具备特殊感知的人则可能同时察觉物质舱室之外的意识活动。克米亚还掌握了能局部削薄“帷幕”的房间与装置：空气压力、声音和视觉几何共同变化，令远距意识接触更容易发生。致幻植物、熏烟、冥想和个人仪式也可能形成较粗糙的通道，但它们既不能保证讯息真实，也不能保护使用者免于恐慌或外来利用。

Parent 所在的层面中，身体只是思想临时采用的形状。物质时间在直接接触期间近乎停滞，数次交流、记忆重现或漫长体验可以被压进外界极短的一瞬。Parent 能读取进入者的表层与深层思想，重组感官体验，展示概率性的未来分支，并把严重受损的肉体修复到常规医学无法企及的程度。它们仍受限制：不能无代价地把一切愿望变成现实，也无法在每一次干预后继续精确预见所有结果。

### 3. 时间、预见与因果

Parent 的心智同时触及许多时间位置。它们观察的未来不是一条固定道路，而是不断分叉、合并和失效的概率网络。某个选择可以提高一条路径的成功率，也可以让曾经最有希望的结局降为低优先级；新知识、强行干预和自由意志都会制造新的变量。Parent 因而既能准确说出遥远未来的一些高概率节点，也可能在关键个体偏离预期行动后失去清晰视野。

过早给予知识尤其危险。一个文明在尚未形成承载能力前得到 Parent 级答案，不只会改变其科技，还会改变每个因答案而作出选择的人，使原本可预测的社会演化变得模糊。Parent 因此倾向于只推动少数关键人物，让他们在不知道全貌的情况下完成整合；这种做法被称为维护 agency，即智慧生命自己选择、行动并承担结果的权利。

Agency 不是不干预的绝对戒律。Parent 曾在战争即将摧毁重要文明时切断 Stretch、制造神迹般的影像并迫使交战者停火；也曾以一人的生死逼迫另一人接受使命。它们一面坚持自由意志是成功整合的必要条件，一面又会在认为整个银河的远景受到威胁时压缩当事人的选择空间。这是银河秩序最根本的伦理张力之一。

### 4. 银河的终极危机

普通生命共同谱系之外，还存在一种来自“别处”的事物，通常只以 **Other** 称呼。Parent 已确认它真实存在、会借宿主想象塑造形貌，并正从宇宙边缘逼近；克米亚的古老解释则把它描述为位于生命与机器边缘、依赖智慧意识才能维持的准生命。它能以宿主的记忆、恐惧和渴望塑造可见形象，再利用宿主的反应扩大影响，但完整物理机制仍不明。

克米亚宇宙传说称，Other 每隔数十亿年经过这一宇宙区域，已留下约半打稀薄、斑块状残余；这些周期数与远古尺度尚未获得直接测量。现时代可以确认的弱态表现，主要是难以解释的声音、错觉与私人化诱惑。枯叶、干燥摩擦和静电噪声组成的意识显现能够模拟死者、亲友或神圣向导，并准确触及目标最深的欲望；其中 The Leaves 无法只靠强制完成支配，必须取得对象真正的同意，因此会先提供安慰、复生、权力、真相或解脱。Other 本体是否受同一同意机制完整约束，仍未得到独立确认。

近十年间，四个具有跨层面传统的 Sibling 文明都出现过“枯叶之声”。来访者因对象不同而采用不同形象，却共享干叶声、私人诱惑、要求同意以及无法进入 Parent 层面的特征。克米亚尚以 **The Leaves** 称呼这一现象；它与 Other 已知碎片的行为高度一致。没有可靠事实表明这些声音兑现过承诺；现有记录也只确认没有已知 sakhaet 向其屈服。

真正的主体正在宇宙边缘汲取存在本身；Parent 预警 Galaxias 将在许多千年后面对与它有关的宇宙级危机。当前任何一个 Sibling 都不足以独自应对。Parent 推动银河一体化的深层目的，不只是维持贸易或和平，而是在危机到来前让分散文明具备共同理解、跨星系航行和集体防御能力。

## 二、Galaxias：银河文明秩序

### 1. Parent、Sibling 与 Child

**Galaxias** 既指由受提升文明构成的银河体系，也指这套体系共享的历史、技术和规范。其基本层级如下：

- **Parent**：从银河之外到来的高层文明或存在群体。它们负责播散文化、选择 Sibling、制定首次接触与提升规则，并在极少数情况下直接介入。
- **Sibling**：被某一 Parent 选中、获得星际技术并承担继续扩展任务的成熟文明。狼族、克米亚诸族、奥莫法猫族、塔哈拉狮族和辛多文明均属于这一层级。
- **Child**：由 Sibling 发现、提升并纳入 Galaxias 的年轻文明。Child 获得技术、教育和保护，同时常背负提升费用形成的债务与服役义务。

这一结构本应是接力而非永久统治：Parent 帮助 Sibling 成长，Sibling 再帮助 Child，最终所有成熟文明都应获得跨越银河、成为新 Parent 的能力。现实中，提升费用、政治附庸和文明优越感常把 Child 置于长期不平等地位。狼族帝国甚至把部分智慧个体降格为可拥有、转让和役使的 pet；克米亚则禁止把智慧生命作为宠物，并会向逃离这类制度的人提供公民保护或庇护。

### 2. 八个 Parent 存在与四组已知纽带

银河中仍有八个 Parent 存在或 Parent 谱系。它们极少公开交流，许多 Sibling 只知道与自身相关的名称。已经明确的对应关系包括：

- **Romanus** 选择了阿达斯特拉狼族。
- **Galenians** 选择了奥莫法猫族。
- **Kemetarians** 选择了克米亚文明。
- **Kushari** 选择了塔哈拉狮族。

Romanus 与 Galenians 来自同一外部银河并一同抵达，彼此之间有极深纽带。Kemetarians 与 Kushari 则源自同一个更古老的提升者；它们在分离数十万年后重逢，重新形成近似手足的合作关系。Parent 间的这些历史会投射到 Sibling 外交之中，但并不意味着两方的每次结盟、战争或偏见都由 Parent 操纵。

Kemetarians 通常被各文明视为 Parent 中事实上的协调者，因此克米亚也长期拥有更高的技术声誉与调停地位。Romanus 对狼族的长期沉默则构成阿达斯特拉政治创伤的核心：一个曾被选中的 Sibling 可以失去资源、失去航行能力，甚至失去自己对银河法则的完整记忆。

### 3. 首次接触法与文明权属

未经 Parent 许可接触尚未纳入 Galaxias 的智慧文明，是足以导致处决和整个 Sibling 被遗弃的重罪。法律的目的，是防止成熟文明以技术优势占有、污染或过早改造年轻文明。它关注的不只是第一次肉体相遇，也包括身份、坐标、技术、文化知识和可追踪证据的交换。

一个文明若曾属于 Galaxias、后来失去全部相关知识，再次接触时仍可能在法律程序上被当作 First Contact。地球正位于这种边界状态：它并非真正与银河毫无历史关系，却没有公开保留自己的来源和身份。狼族个体私自把人类从地球带走，因而同时触犯帝国法与 Parent 的神圣规则。

Parent 并未把 Sibling 之间的关系设计成竞赛。各国长期以为只有最强大、最纯正或最受宠的一方能升为 Parent，于是把扩张和压制合理化。真正目标恰恰相反：没有任何一方能独自完成跨银河跃迁，所有 Sibling 与 Children 必须汇集知识、资源和文化，才可能使整个体系成熟。这个过程已经持续约两万年，仍远未完成。

### 4. 提升、债役与失落文明

提升通常包括语言与知识接入、医学、能源、星际航行、政治指导和进入 Nexus 类信息体系。它也会重塑被提升文明的权力结构。先进器械往往先集中于王室、军队或受 Sibling 支持的统治者手中；提升债务则把劳动、资源和军事义务固定为代际负担。制度的名义是让 Child 偿还文明改造成本，实际效果可能接近有法律包装的依附或奴役。

一次失败的提升不会自动抹去 Child 的身份。文明可能崩溃、被屠杀、断绝航路，或只留下极少幸存者，但它仍属于 Galaxias 的历史责任。德萨雷斯地下狼獾文明正是最惨烈的例子：克米亚开始提升后，狼族对其发动突袭，数以十万计的新生 Galaxias 成员在尚无能力自保时死亡。这场灾难不是简单的两国领土冲突，而是对提升义务本身的破坏。

## 三、Parent、Monitor 与死后意识

### 1. Parent 的存在方式与能力边界

Parent 已越过普通肉体文明的阶段。它们能够在思想空间中塑造环境和身体，直接读取进入者的记忆，把多个时间片段并列展示，并以物质文明无法复制的精度重建人体。人类喉管、气管和声带遭到致死性破坏后，Parent 不仅恢复了生命，也重建了发声结构；狼族严重眼部及颅骨创伤也可借其技术在极短时间内安装与神经整合的视觉装置。

这些能力不能等同于传统意义上的神。Parent 会等待、犹豫、比较概率，也会因未知变量而调整方案。它们不能从物质层面随意消灭所有敌人；越频繁地改写事件，越难预测自由个体接下来的选择。其力量更接近跨层面文明与超长期因果工程，而不是无条件实现愿望。

Parent 的公开原则包括：尊重智慧生命的 agency；仅在文明无法自行跨过关键障碍时介入；让每个世界以自己的方式完成整合；防止一方永久奴役另一方；最终使银河共同成长为能够向外传播生命与文化的新 Parent。它们的实际手段却常带有冷酷的工具性。个人可以被安排为历史角色，爱情与死亡可以成为迫使其履职的杠杆，一整个世界也可能因总体成功率过低而只得到最低限度的观察。

### 2. Monitor：跨层面的桥梁

**Monitor** 是 Parent 为连接自身层面与物质银河而设计的观察者。它是 Parent 的眼与耳，能够追踪关键个体、听见思想、进入梦境般的意识空间，并在条件合适时开启直接沟通。它没有展现出在思想空间中直接杀伤目标的能力，也不具备 Parent 的全部知识和权力。

Monitor 并非只会复读命令的空壳。它有语气、偏好、急迫、挫败和独立判断，会隐瞒尚不允许公开的部分，也会对 Parent 的决定表现出自己的反应。其知觉可跨越物质距离，也会被人类的意外行为打乱；The Other 能侵入与受监视意识相邻的层面，但 Monitor 是否也可能被它欺骗尚未证实。对受监视者而言，它既是向更高层求助的唯一稳定桥梁，也是无法拒绝、无法确认完整动机的隐形监督者。

Monitor 在阿达斯特拉危机中推动了两项互相衔接的任务：让新帝停止狼族的自毁循环并重新连接其他 Sibling；让来自地球的人类返回故乡，在不向大众揭露全部宇宙真相的情况下促进人类国家整合。第一步以克米亚联盟为起点，第二步预计持续八年。两人都只得到完成眼前阶段所必需的信息。

### 3. Amalgamation 与 Greater Intelligence

智慧个体死亡后，意识并不必然与肉体一同消失。广为接受的解释是：死者会进入 **Amalgamation**，融入由无数意识组成的 **Greater Intelligence**。它不是保存原样肉体和日常生活的普通来世，而更像记忆、人格与感受汇入一个巨大意识海洋。Parent 与 Monitor 能辨认其中的个体痕迹，并把某些亡者描述为与所爱之人共同安息。

争议集中在“融入”是否仍保留足够的自我，以及个体能否拒绝。Marco 直接经历过意识汇入 Greater Intelligence 并被抽回，证明融合现象本身存在；Monitor 则称真正的 Meera 已在 Amalgamation 中与 Drusus 安息。Khemia 出现的 Meera 形意识自称从未进入融合体，其身份至今未明。The Other 又擅长借宿主记忆模仿亡者，因此外貌、私密记忆和自报身份都不足以证明一次显现确为死者本人。

### 4. 专职沟通者

至少四个 Sibling 文明保留了与 Parent 接触的专门传统：

- 克米亚的沟通者称为 **sakhaet**。现任者 Aya 是阿霍特普统一以来第八十三位，自十五岁开始训练，实践约五年。按统一年代与八十三任传承推算，每任覆盖的平均时段超过一百五十年；职位通常终身承担，却也存在空缺与在世交接，因此该数值不是物种平均寿命。
- 塔哈拉的同类职位称为 **dakhur**，狮族 Zanmek 属于这一传统。
- 辛多拥有极古老的沟通法，其历史比许多现存国家更长。
- 奥莫法人借助经过控制的植物与致幻体验削薄意识边界。

狼族没有稳定保留相同制度。其古老熏烟与冥想法确实可能打开通道，却缺少连续训练、风险控制和对异常意识的辨别体系。

专职沟通者接收到的通常不是清楚句子。Parent 以情绪、方向感、压力、认可或回避传递指引，而且不会对每次呼唤作出回应。沟通者也不能任意读取旁人的思想。远距心灵接触只会在两个同样具有柔韧心智、彼此认识并形成联结的人之间稳定发生。初次打开能力需要一个个人化的 **key**：掌纹、石块、晶体、呼吸或冥想动作都可成为聚焦媒介；一旦“门”被真正开启，后来即使没有原媒介也可能再次进入。

## 四、科技与基础设施

### 1. Parent 遗产与文明自主技术

Galaxias 科技可分为三层。第一层是 Parent 直接给予、使用者并不真正理解的遗产，例如早期 Stretch Drive、lingua 和部分高级医学。第二层是 Sibling 对遗产的维护、仿制和本地化，例如狼族 Com、无人机与自动运输。第三层是文明在掌握原理后独立超越旧赠礼的成果；克米亚已能制造速度更快的 Stretch 装置、改写 lingua 功能，并以自己的材料、能源和计算体系重现近似 Parent 的效果。

技术先进不代表社会处处便利。阿达斯特拉皇宫拥有自动清洁、武装无人机、全息界面和复杂医疗，偏远城市却仍依赖步行商队、自动马车和河船；中央政府能监控客房，普通居民则可能得不到可靠公共交通。技术分配本身就是权力与阶级的地图。

### 2. Stretch Drive

Stretch Drive 是已知 Sibling 星际文明的基础。它让飞船脱离常规航行尺度，以有限能量跨越恒星间距离。距离越远，所需能源越高；它不能把任何地点无条件连在一起。对仍依赖 Parent 核心、能量或授权的舰队，Parent 能切断 Stretch 访问，使其困在本恒星系；狼族在帝位空缺期和第三次奥莫法战争中都经历过这种制裁。克米亚自主制造的现代驱动是否仍可被同样方式全面停用，尚未得到证明。

进入 Stretch 后，舱外景物和室内光线像被沿着不可见方向拖曳；人体的平衡感、胃部和时间感会短暂失配。层面边界同时变薄，使敏感意识听见或看见正常空间中不存在的东西。Parent 跨越银河所用的方法不等同于普通 Stretch，现有 Sibling 尚未达到真正的跨银河旅行能力。

### 3. Lingua

**Lingua** 是植入脑内的翻译装置，核心可小至不足一毫米的金属球，内部含有成分不明的液体。它不只是把词典逐字映射，而是向宿主提供当下最容易理解的等义表达，使异族说话听起来近似自然配音。它能处理大多数日常语言，却会在歌唱、双关、专名、文化中不存在的概念或从未学习的词上失效；听者可能只感到音节陌生，或得到过度简化的近似意思。

克米亚能通过 lingua 安装通信和计算接口，使个人直接访问网络或随身 Ahm。植入仍有权限边界：翻译、通讯与读取思想不是同一功能，拥有 lingua 不代表任何政府可自动查看宿主全部内心。

### 4. Com、Nexus 与 Ahm

**Nexus** 是连接人员、地点和信息的网络基础，承担检索、新闻、通讯与远程资料访问。**Com** 是阿达斯特拉常见的计算助手及宫殿控制系统。它可用语音响应命令，管理门锁、灯光、清洁、客房、医疗呼叫、无人机、档案与计时，也会严格服从身份权限。皇帝、皇室成员、侍卫和普通住客能看到的内容不同；一项命令被标为帝国机密后，低权限者甚至无法得知囚犯所在。

Com 的流畅回应不应被误认为真正有自我意识。已知 Sibling 仍未稳定创造具有完整人格的思考机器。Monitor 的人格性来自跨层面设计，不能归入普通人工智能。

**Ahm** 是克米亚由国家出资、研发并拥有的高阶计算系统。它能通过 lingua 随身运行，协助搜索、导航、翻译、环境判断和私人事务；也可进入避免外放声音的私密模式。Ahm 服从明确的国家权限序列，法老、维齐尔及获授权人员对机密拥有不同等级。即便其表现远胜普通 Com，也没有证据确认它已经成为独立智慧生命。

### 5. 无人机、武器与交通

悬浮无人机遍布宫廷和富裕设施。小型机负责清洁、送餐、搬运行李、递送药品和持续监控；安保型号可发射致昏迷或致伤的能量束，并在系统授权下封锁房间。狼族皇室掌握的高端型号远多于地方居民，私人空间也可能在不知情时被监视。

城市间交通同时存在多种代际：星际飞船与短程飞行器速度最快；自动 chariot 承担普通陆路客运，从 Lux 前往首都约需两周。Lux 的原料和货物则先由步行队伍或马车送到河边，再以不载普通旅客的货船运往 Tricelli 加工分配。**Sightseer** 是皇宫湖面的透明观光悬浮艇，并非城际地面载具。

### 6. 医疗、寿命与物种适配

普通 Galaxias 医学已能快速扫描、缝合创伤、提供针对物种的药物和疫苗，并用周期性补充剂延缓衰老。狼族的维护方案可额外延长约两百年；成年后才开始接受治疗的人类收益较少，常规估计只能再获得约一百年，使总寿命落在约一百五十至两百年范围。Parent 的条件性未来显示一名人类可接近三百岁，但这一寿命究竟来自未来医学、个体变化还是 Parent 干预并未说明，不能归因于常规延寿剂本身。

跨物种治疗必须定制。药物剂量、麻醉、热调节和病原免疫不可仅凭外形相似套用。狼族浓密毛发在寒冷环境中有利，在克米亚炎热空气里却容易造成热应激；人类靠全身出汗散热，对阿达斯特拉医生而言反而罕见。每个新抵达者通常需要检疫和一组针对当地病原的疫苗。

**Avia pox** 是跨物种风险的典型。它对狼族与既有灵长类样本极为温和，因此当时根本未被纳入新到访者的常规疫苗组；Marco 又因秘密抵达绕过完整入境检查，医疗系统也没有 Human 档案。即使走完旧流程，既有疫苗组本身也不会覆盖 avia pox。Marco 经 Parent 直接重构后仍会间歇性排毒，是否已经存在经验证的 Human 专用疫苗并未明确。除 Marco 外，现有七名 Human 病例全部死亡：三名美国外交人员和由其中一人感染的四名英国官员相继死亡，谈判因此停摆。

### 7. 能源、材料与环境工程

克米亚的 **Sahira’s Tower** 是行星级能源设施。它从恒星获取能量，再以橙粉色光束输送到行星系统，为整个克米亚供能。克米亚还能控制大尺度环境，使原本极度缺水、热量分布严酷的世界维持遍布地表的文明。宫殿使用吸收声音的纳米材料、视觉错位结构、悬浮水景和无缝环境控制；古代石造建筑则被持续维护数千年，而非被新技术完全替换。

奥莫法技术沿另一条道路发展。猫族把活藤、枝干与机械结构结合，让植物承担药理、感应和通信功能；巨大的枝状天线可进行远距联络。其植物药学与致幻知识尤其成熟，现已部分共享给克米亚。活体技术不是装饰风格，而是一套以生长、代谢和可培育材料替代纯金属器件的工程体系。

## 五、智慧种族与生物生态

### 1. 物种、国籍与文明身份

外貌物种、行星国籍与 Galaxias 身份是三套不同分类。一个豺形个体可以是克米扬公民、Kemetarians 选择的 Sibling 成员和王室成员；一个狼獾形个体同样可以拥有克米扬国籍并担任高级外交官。把所有克米扬都叫作“豺”，就像把所有地球人都叫作某一个民族，既不准确也可能构成冒犯。

许多文明以最常见或掌权物种形成外界简称。阿达斯特拉帝国以狼族为绝对主体，奥莫法常与猫族相连，辛多与虎形智慧种相连，塔哈拉与狮族相连。然而，除阿达斯特拉的高度单一化结构外，不能由一个代表形象推断整颗行星只有一个智慧物种。克米亚由十五个物种构成，jackals 占总人口六成以上，但“Khemian”仍不是“jackal”的同义词。

### 2. 阿达斯特拉狼族

狼族是大型披毛犬科智慧种。成年个体普遍高于普通人类，肌肉密度、爆发力和抗冲击能力也明显更强；约三百磅的成年雄性并不妨碍快速奔跑、跳跃、摔抱与游泳。手足为带肉垫和爪的 paw，头部具有长口鼻、可转动耳朵，身后有能泄露情绪的尾巴。它们对气味与细微身体信号极为敏感，可从残留气息辨认陌生来访者、血液、恐惧、香油和近期亲密接触。视觉并非唯一主导感官。

狼毛需要大量维护。洗浴后通常用强风吹干，顺毛梳理，再涂蜂蜜色护理油和紫色薰衣草香液；香液既是身份与亲密照料的一部分，也用于压住浓重体味。浓密毛层适应较冷环境，却会在克米亚干热中快速积蓄热量。出访当地的狼必须降低活动量、补水和寻找阴影，长时间直晒可能中暑。短毛豺族对此耐受得多。

狼族并非不会游泳。幼年可绕湖岛竞速，传统泳法依靠强力扑划，爆发快但耗能；竞技者还会把毛剃短以降低阻力。人类自由泳的连续划水技巧能被狼在短时间内学会并显著提高效率。Galaxias 旧知识曾把灵长类概括成“不会自然游泳、落水即死”，人类的表现证明数据库常把缺乏本能误判为无法学习。

狼族的情绪可从耳位、尾姿、毛发、喉声、嗅觉变化和身体距离中读取。咬颈、抓挠头毛、贴面、把口鼻靠近颈侧都可能是亲密动作，也可能在权力不对等时带有占有意味。牙和爪在搏斗中足以造成致命伤，因此正规 pugnu 明禁用爪、牙、挖眼和攻击腹股沟，训练还会避免击打颈部以上。

帝国以阿达斯特拉本地年份计算成年，二十岁为重要法律门槛。自然寿命没有统一公开数值；高阶医疗与月度身体调节能令精英活过多个普通人类世代。不能把享有 Parent 补充剂的皇室寿命直接当成全体狼族平均寿命。

### 3. 人类

人类是地球本土灵长类智慧种。与狼族相比体型较小、皮肤大面积无毛、爪牙攻击力低，但具有精细手指、较高耐力、靠全身出汗散热的能力和可通过训练掌握的高效游泳技术。对狼族医生而言，大量出汗很容易先被误认成急性疾病；对人类而言，狼的气味、体温和毛发则比日常地球经验强烈得多。

人类的技术发展不均衡：尚无公开星际航行，却在某些社会技术、人口组织与局部工程上不逊于乃至超过衰退期阿达斯特拉。地球人口约七十亿的规模令仅有约八千万狼族的帝国震惊。庞大人口、多国家体系和多重文化既让统一极难，也使人类拥有任何单一 Sibling 都不具备的内部多样性。

人类最危险的生理弱点是对 avia pox 的异常易感。其他灵长类的既有医学经验无法保护人类；接触流程必须增加病原筛查、隔离、排毒监测、接触者追踪与 Human 专属药理验证。经验证的 Human 专用 avia pox 疫苗是否已经存在并未明确。任何把人类当作“又一种普通灵长类”的医疗体系都会重演致死事故。

### 4. 克米亚多物种共同体

克米扬是政治共同体而非单一生物种。豺形人口构成王室及多数外界熟悉的面孔：短而贴身的毛使肌肉轮廓更清楚，适应沙漠热风；嗅觉普遍被认为不如狼敏锐。克米亚由十五个物种构成，jackals 占总人口六成以上；Brunis 则证明狼獾也能成为 Khemian 公民与高级外交官。另有约二十万 Omorfan 居民，但他们是否计入这十五个物种并未说明。多物种社会必须面对不同身高、毛量与生理带来的建筑、药物、服装、餐食和交通适配问题。

这种多物种性也塑造了克米亚的政治伦理。公民权优先于外貌血统，国家承诺庇护逃离狼族压迫的任何智慧生物，包括狼族自身。智慧 pet 被视为违法制度；外交使团成员享有豁免；公民依法可以批评法老。制度并未消除王室越权、监控和秘密关押，但这些行为属于对现存法律的破坏，而不是公开被承认的正常权利。

### 5. 奥莫法猫族

奥莫法猫族是 Galenians 选择的 Sibling，也是已知科技最先进的文明之一。身体同样披毛，情绪剧烈时眼部会流出液体；狼族曾把这种生理反应误解为异样。猫族对深水和大面积水域普遍不适，却不能由此断言所有个体都不会游泳。

奥莫法的提升理念与狼族相反：Children 应尽量成长到与 Sibling 相当，而不是被刻意压低智慧或锁在债役中。其活体植物技术、药理和长距通信高度成熟。一个隐蔽在巨树树洞里的微型装置，可以让整棵树的枝冠充当天线，把信号送往城市，再经第二节点转发到星际设备。奥莫法也有发达的情报体系，并曾利用外交、亲密关系与帝国 pet 制深入阿达斯特拉权力核心。

### 6. 辛多虎族与塔哈拉狮族

辛多文明至少包含虎形智慧种。约一万年前，雌虎梅拉参与狼族重新接触银河的历史转折；后世阿达斯特拉舞剧用蓝金长裙和在人脸、裸臂上涂黑纹来模仿辛多女性，这种做法被狼族视为致敬，却可能被真正辛多人视为浅薄甚至冒犯。辛多后来与阿达斯特拉断绝通信，并保留了极古老的跨层面仪式传统。

塔哈拉以狮族为代表，是技术水平仅次于最先进一方的 Sibling，与克米亚长期结盟。其 Parent 为 Kushari，专职沟通者为 dakhur。第二次阿达斯特拉—克米亚战争中，塔哈拉曾援助克米亚。当前 dakhur Zanmek 以石块和晶体作为意识之门的 key，并能与克米亚 sakhaet 在非物质层面保持远距友谊。

### 7. 德萨雷斯狼獾

德萨雷斯的智慧狼獾是地下演化的文明。阿达斯特拉曾先行勘察其世界，却没有发现地下居民，随后把勘探权出售给克米亚。克米扬在很短时间内发现智慧生命，并开始持续提升。狼獾在最脆弱、最依赖保护的阶段卷入两大 Sibling 的资源与主权冲突，最终遭受几乎灭绝的突袭。

Brunis 是两名仍存活的德萨雷斯狼獾之一，也是已经确认的 Khemian 公民与驻 Adastra 大使；另一名幸存者的身份、处境及两者是否留下后代均未公开。厚毛、高大体格和地下起源只是适应地下生态的生理结果，与文明程度无关；真正定义其现代处境的是大屠杀、流亡与被两国删改的历史。

### 8. 非智慧动物与植物

阿达斯特拉温暖湿润地区拥有高大森林、藤蔓、灌木、白色小花、湖滨草地和尺寸惊人的节肢动物。皇宫花园可见张腿宽如钟面的类蟹蜘蛛，黑色小眼、移动极快，能攀上石柱和身体；其毒液通常只造成瘙痒与肿块。无人机虽负责灌溉和害虫控制，仍保留这些动物维持生态平衡，只清除真正危险或越界个体。森林夜间和幽暗处有发出微光、近似萤火虫的飞行昆虫。关于 **Simiarbor** 的传闻则更接近林地怪谈，尚无可靠捕获或生态分类。

克米亚原生赤道生态截然不同。那里热、干、缺水，原始地表只容纳体型小却数量繁多的耐旱植物，大量昆虫生活在地下。夜间沙地会出现蝎子，蜇刺可造成持续数日的剧痛；衣物、床褥和阴影缝隙都需检查。当地也有大型毛蛛，已知最大类群近似 tarantula。大规模环境改造让文明覆盖赤道，却没有把所有本地生物抹除。

**Chronoma** 是奥莫法原生精神活性植物，克米亚培育品系称 **pap**，蒸吸制剂称 **papywei**。其绿色碎叶带浓烈草本气味，可缓解慢性疼痛、运动病和精神负担，使思路放慢、情绪意义增强、共情更明显。初次反应不可预测，依赖与成瘾确实存在；克米亚通常由 Ahm 根据症状限量提供，而非无限供应。阿达斯特拉将其列为非法药物，并常用街头成瘾者影像把整个制度描述成失控毒品文化。

## 六、天体、地理与环境

### 1. Stella Vita 恒星系

阿达斯特拉所在恒星系以 **Stella Vita** 为中心，日轮也常称 **Vita**。可见的主要天体包括：

- **Ancoris**：粉笔灰色、高重力、空气不可呼吸的行星。
- **Adastra**：绿蓝色宜居卫星，绕 Ancoris 运行，也是狼族帝国本土。
- **Torque**：更小、近乎纯白的另一颗卫星。

从飞船接近时，阿达斯特拉呈有水体与植被的绿蓝色；Ancoris 则缺乏适于无防护生活的表面环境。两颗卫星在天空中的位置与 Ancoris 的巨大存在共同塑造本地天文经验。阿达斯特拉一日约十九小时，短于地球日；清晨适宜户外活动的凉爽窗口约三小时，随后热度迅速上升。计时会经 lingua 换成听者能理解的“小时”，但十九小时日制是稳定的相对尺度。

### 2. Ancoris：矿场与流放地

Ancoris 的空气不能直接呼吸，工作者必须生活在密封基地并穿防护服。行星重力会持续损伤骨骼、肌肉、内脏和心血管系统；长期停留者即使返回阿达斯特拉，伤害也未必逆转。这里既开采矿物，也是帝国放逐罪犯和政治敌人的地点。流放因而不是换一座城市居住，而是把人送入会缓慢破坏身体、又难以逃离的工业殖民地。

皇帝可把地方民选官员及其家族一并流放 Ancoris，显示中央权力能绕过地方选举，以连坐方式惩治挑战者。已知流放者居住在密封基地、穿防护服采矿；是否另有自愿矿工、刑期如何计算以及返回保障如何规定，均未公开。

### 3. 阿达斯特拉大陆与首都盆地

已知陆地至少包括名为 **somni** 的南部区域；同名植物正产于大陆南方。帝国拥有七座主要城市；Potes 死后的皇位 Trial 则由五个地方 triumvirate 单位与 Cato 所代表的中央“Adastra”单位裁决，两组数字并不描述同一集合。主要城市之外还有小型省区、乡村与其他聚落。现有地理不足以断言整颗卫星只有一块大陆。帝国总人口约八千万，其中首都超过五百万；人口密度远低于现代地球，且受长期人口控制影响。

**Adastra City** 坐落于大型湖泊对岸或沿岸盆地。由皇宫阳台望去，粉橙色晨光先照亮云层，再落到山丘与密林；城市中央是最高的玻璃或晶体般巨构，向两翼逐渐降低，夜间窗灯稀疏闪烁。椭圆飞行器以蓝红航灯下降，巨型屏幕和联网新闻覆盖公共空间。城市主要容纳帝国官员及家属，是行政首都而非最富娱乐性的商业都会。

首都的富裕区、贫困区和皇宫并非同一生活世界。**Imperial District** 集中权贵与外交住宅，地方 magistrate 仍可利用住房法规驱逐不受欢迎的王族外宾。**Silk District** 提供短租与较普通居所。**Clay District** 最贫困，反精英与分离主义情绪强烈，显眼的皇室或外交人员可能在街头遇袭。宫廷具备星际医疗和无人机安保，首都之外却连基础疫苗都可能负担不起。

### 4. 皇宫、湖泊与岛屿

皇宫以石材、大理石、拱门、柱廊和大面积开放空间构成，紧邻冷而略浑浊的湖。宫内常住智慧个体很少，清洁、送餐、裁衣、灌溉、警戒和摄录主要由 Com 与无人机完成。宽阔走廊因缺少仆从和卫兵显得空旷；高技术并未制造人群繁忙感，反而让权力中心安静得近乎私人宅邸。

主厅拱门通向花园，藤蔓沿石面攀爬，灌木和白花围绕池塘，树荫下设长椅。空气温暖湿黏，临湖清晨则清新一些。古老密林从宫城道路延伸出去，扭结粗糙的树干和密闭树冠把日光滤成幽绿色，微光昆虫在阴影中漂浮；烈日下则需要扇子和遮荫。

湖水表面宁静，实际冰冷、略受污染，浅岸有流动沙底。岛屿离岸不远，面向皇宫一侧有沙滩，背面被浓密乔木和灌丛覆盖，几乎没有开阔滩。正午干沙会烫伤人类赤足，湿沙和浪水又会迅速带走热量。岛上古树内部可隐藏奥莫法活体通信设备，树冠天然成为难以被普通扫描识别的天线。

宫殿设施包括王座厅、宴饮厅、小型下沉式 pugnu 露天剧场、冥想室、档案区、医疗设施、客房和公共矿物浴场。浴场充满热水与蒸汽，石池水体有不同矿物成分；冥想室则小而朴素，空气因熏香变得温暖厚重。地下地牢从隐蔽小室的地坑和梯子进入，石墙石地寒冷潮霉、照明昏黄，与上层明亮庭园形成强烈断裂。

### 5. Trial 裁决单位与七座主要城市

该次 Trial 的六个裁决单位并非六座同构城市：Lupas、Ad Rotae、Lux、Gebii 与 Tricelli 各由地方 triumvirate 投票，Cato 则代表中央“Adastra”单位，并在修辞项中拥有等同两个地方单位的票权。帝国另被明确称为拥有七座主要城市。**Lex** 与 Lux 不同且经济状况良好，但它是否正是未参加该次 Trial 的第七座主要城市，并未被直接界定。

**Ad Rotae** 是最富裕的娱乐和度假城市，拥有大量食物、舞台表演和尺寸夸张、可靠性令人怀疑的游乐设施，整体气质近似把大型赌场城与主题乐园合并。它的经济与首都行政职能不同，最能吸引追求消费和 spectacle 的游客。

**Lupas** 是文化中心和第二富城市，人口约一百五十万，而普通主要城市平均约三百万。它在五千多年前曾不足十年地充当临时首都，留下强烈的历史自尊。现代 triumvirate 被少数富裕家族控制，要求更多投票权甚至否决权；地方同时存在分离主义、狼族旧神崇拜和至上主义团体，以炸弹、焚烧克米扬与人类形象等方式制造压力。其近期资金流异常，但外部资助来源尚未确认。

**Tricelli** 曾在比 Lupas 更晚的时期充当临时首都，持续时间也更长。它是 Lux 资源离开山区后的加工与分配枢纽：原料沿陆路和河运抵达，在此精炼，再送往帝国其他地区。它既依赖边区产出，也从边区无法自行控制的价值链中获利。

**Gebii** 是五个地方计票单位之一，但现有公开地理与产业细节很少。它在皇位 Trial 中拥有与其他外城同级的三人代表权，足以说明并非小型附属聚落。

### 6. Lux：北方资源边疆

Lux 位于遥远北方的山地冻原，别名 **City of Defiance** 或 **City of Rebellion**。抵达前要穿过锯齿状雪山、起伏丘陵、巨大裸岩和褐色近似枯死的植被；农舍与加工点彼此隔得很远，山谷风寒冷而干硬。城市本身呈灰暗、拥挤而戒备的面貌，街道在宵禁后几乎无人，居民从窗后观察来访者。公开鞭刑、严格宵禁和示威镇压让反抗与国家暴力形成日常循环。

Lux 是帝国最大的天然资源产地，却长期贫困、孤立并依赖低效运输。山区没有能直接把大宗货物送往中央的完整网络，物资先由人力或自动马车送到河边，再由船前往 Tricelli。中心得到矿物与农产，地方却承担寒冷、危险和基础设施不足。罢工与骚乱会立刻冲击全帝国供应，于是中央常在危机爆发后让步，却很少解决让危机反复出现的结构。

城市约一英里外有皇室 villa，既是政治监视点也是与市民隔离的舒适住所。Lux 山中存在天然硫磺温泉：泉水清澈、触感柔滑，热度高于皇宫浴池，冷空气中蒸汽带有矿物与硫气味。帝国其他浴场会人工模拟其矿物成分，天然泉因而成为少数可吸引外来者的旅游资源。

Lux 的反克米亚情绪极强，教育程度低、对中央史学不信任，又因德萨雷斯战争与资源问题成为政治宣传争夺地。它并非天生好战；长期被置于不利分配、只在暴动后才获回应，才使温和行动难以维持声望。皇室巡访、公开 pugnu 表演和临时代表承诺可以短暂缓和局势，却无法单独修复运输、贫困和地方权力问题。

### 7. 克米亚行星

克米亚是完整行星，表面积约为阿达斯特拉的十二倍。从轨道看，它像覆盖尘埃大气的米黄色沙球，人工文明在地表画出大面积规则线条与图案。行星一天约二十二小时。轴倾角使极地冰融水能够在边缘地带形成稳定水源；若没有这项天文条件，本土智慧生命可能根本无法演化。

前统一时代的定居带围绕两极水源形成，彼此跨越赤道如同后世跨越星际。赤道原本极热、极干，只有地下昆虫和小型耐旱植物大量生存。克米扬后来对全行星实施 terraforming，使文明设施进入环赤道地带，却仍保留沙漠、尘层、热风与昼夜温差。白日沙地灼热，干燥与高温会使来自阿达斯特拉的厚毛狼迅速积热、出汗并面临中暑。

### 8. Khemen、Aarum 与王宫

**Khemen** 是克米亚首都。当前外来使团由飞船直接降入王宫庭院，厚重宫墙遮住城内街景，因此首都普通街区的尺度、行业与居民生活尚未完全展现。王宫不靠巨大体量炫耀，外形强调直线、角形和清晰轮廓；墙面以鲜艳画带和上下排列的凹刻象形文字记录多物种日常、仪式与神圣图景。

古老石面历经数千年风化和褪色，却被维护而非替换。克米亚建筑哲学把这种历史累积称为 **babekhen**，即“建筑之魂”：长期存在的建筑被认为会吸纳周围事件与生命，从而形成比最初建造者更持久的身份。许多结构依据 Kemetarians 早期接触时赐予的 vision 设计，古代宗教几何与现代工程因而共存。

宫内空气带香料草本 incense，长廊利用视觉 illusion 显得远超实际长度。吸声纳米材料和主动噪声抵消让大部分空间近乎窒息地安静；用于密谈的房间反而布置多个水池与喷泉，以连续水声遮蔽窃听。庭院中央有靠机密技术悬浮的水球或喷泉，水在沙漠文明中同时象征古代生存、王权与现代控制力。

隐藏的 contact room 入口环绕古老象形文字，由 Ahm 按个人授权开启。穿门时会出现特殊声音和空气压力，墙线、曲面仿佛退向远处；地面细软如面粉或流沙，却不粘附毛皮和衣物。内部 veil thinner 人为削薄层面边界，使具有天赋者更易打开意识之门。

**Aarum** 是前 Galaxias 时代最强的水王国，保存的古建筑和纪念物甚至比 Khemen 王宫更壮观。**Amadun** 则是王室长女 Henut 接受某种训练的地点；训练是否与继承有关仍属王室机密，不能仅凭地点推定具体设施。

### 9. 地球与其他已知世界

地球拥有海洋、众多大陆、约七十亿人口和由主权国家组成的政治体系。意大利罗马保存了 Roman Forum 等与 Romanus 早期提升相关的遗迹，却已被人类解释为自己的古代史。美国、英国、欧洲机构及其他国家分别参与世界整合谈判；任何一国都不能代表全体人类，Parent 所要求的“统一”也不是单纯由某个国家征服其他国家。

**Omorfa** 距阿达斯特拉比地球更远，当地一日可长达约三十小时。其自然环境拥有能与机械共生的植物技术资源，水域对猫族文化有特殊心理分量。**Taharka**、**Hindo** 的完整地理尚未公开展开。德萨雷斯原乡又以探测编号 **Quarto-2413b** 被提及，距离阿达斯特拉约五十七光年；二者极可能指向同一狼獾世界，但双重命名关系尚未得到完全确认。

## 七、阿达斯特拉帝国：政治、法律与社会

### 1. 皇权与地方三人执政团

阿达斯特拉是以皇帝为中心、地方选举与中央世袭并存的帝国。皇帝掌握对外关系、Parent 通信、军队、宫廷系统、国家机密和重大刑罚，能关闭 Nexus、调动武装无人机、授予访问权限、驱逐或流放地方官员。其命令可以在没有大批官僚现场执行的情况下，经 Com、飞船和自动系统迅速落地。

五座参与该次 Trial 的外城各由三名民选官员组成 **triumvirate**。地方三人团负责城市治理、代表地方利益，并在这次皇位空缺中参与裁决。制度让外城拥有制衡中央的渠道，却也容易被当地富裕家族垄断。Lupas 的三人团便长期受少数家族控制；Lux 的地方权力则与贫困、宵禁、公开惩罚和资源利益交缠。

首都由皇帝与中央体系直接代表。皇帝可以惩罚 triumvir，却不能在不引发政治反弹的情况下随意抹去全部地方代表。Cassius 曾提出谨慎废除各城三人团、让中央直接统治，消息泄露后，地方代表在皇位 Trial 中几乎一致反对他。由此可见，地方票不仅评判候选人的才艺，也保护投票者自身的制度生存。

Amicus 登基后尝试引入共和国成分：建立 Senate，让各城取得更明确的投票权。改革尚处于不稳定早期，参议院已经发生公开斗殴，被其他 Sibling 新闻作为“狼族缺乏文明协商能力”的证据传播。新制度并未立即取代皇帝或 triumvirate，而是叠加在旧结构上，形成皇权、摄政、地方代表和新参议机构并存的过渡状态。

### 2. 帝位继承与三项 Trial

前皇帝突然死亡且没有无争议继承人时，代理统治者 Cato 让两名皇子以三项 Trial 决定帝位：

1. **音乐与舞蹈**：两组候选人与 pet 实际都选择表演《Meera》，并接受传统修养、教导能力、情绪感染与公共形象评判；Meera 是否为规则强制题目并未说明。
2. **修辞**：候选人针对各城利益发表全国直播演说，规则重视说服力与戏剧性，并不核实每项政策是否真实可行。
3. **pugnu 战斗**：若前两项一胜一负，以徒手格斗决胜；若一方连胜两项，理论上可取消第三项。

首项由五城 triumvirate 各作为一个计票单位，Cato 代表中央；修辞项中 Cato 的票权等同两个地方单位，胜出需四个地方单位，或两个地方单位加中央。比赛在王座厅直播，全月放假观看，无人机从顶棚拍摄，窗墙调暗、聚光集中于表演者。地方民选代表、中央代理人和全国观众共同制造合法性，但正式比分仍可与大众情绪相反。

这次三项 Trial 不是历代继承危机皆循的稳定宪制，而是 Cato 在 Potes 死后采用的裁决方案。Cato 可以临时取消资格、关闭直播、伪造战斗影像并以安全为由强迫候选人输掉比赛；掌握无人机、医疗和录影的人便能制造“看似合法”的新帝。该次 Trial 因而成为权力制衡、国家戏剧和宫廷政变工具的混合体。

### 3. 皇帝、伴侣与摄政

帝位长期由男性狼掌握，皇帝的公开形象被期待包含力量、异性繁衍与对 pet 的支配。同性亲密并非社会中不存在，pet 与主人之间的性行为也不自动被归为同性关系；但男性候选人与平等身份男性相恋，可以被政治对手包装成软弱、受外族控制或不适合延续皇统。社会接受私下行为，不等于接受其改变权力与家庭结构。

女性受到系统性低估。她们可掌握外交、情报、会议和危机决策，却常被预设缺乏统治能力。历史上 Drusus 之前的女性统治者几乎都被后世描述为灾难，这种一致性更可能反映史学偏见与政治污名，而不是所有女性恰好无能。Virginia 正是利用男性对“愚蠢女性”的预期隐藏判断，后来在皇帝外访时成为 acting empress 或 Empress Regent。

摄政权仍受性别现实限制。Lupas 等地方更愿接受男性共同统治者，Virginia 因而考虑让 Cassius 以 magistros／首席顾问乃至 co-ruler 身份共同稳住政局。这样的安排既可利用 Cassius 的旧人脉，也可能把女性法定权威重新绑在男性认可之上。

### 4. 法律、刑罚与帝国暴力

对皇帝说谎可以判死刑；未经许可的 First Contact 也可处决，并可能引来整个文明遭 Parent 遗弃。帝国法适用于领土内的外国人，外国公民身份只会制造外交威慑，不自动豁免本地管辖。Khemian citizenship 能阻止秘密处置的政治成本，却无法在一瞬间解除客房门禁、pet 义务或皇帝命令。

刑罚包括监禁、公开鞭打、处决、矿场劳动和流放 Ancoris。传统皇室侮辱与威胁中还存在阉割。边区公开鞭刑和严格宵禁是维持秩序的常见手段；首都处决则可被安排成露天剧场中的全国 spectacle。帝国会以家族连坐惩罚地方官，也能让调查人员消失、封锁坠机调查和改写官方叙事。

法律与系统权限紧密相连。地牢位置可被标为皇帝机密，探视以二十分钟自动计时；房门、无人机和 Com 根据身份决定服从谁。掌握合法账号的人甚至不必亲自持械，便能把一个人变成无法离开房间、无法查询同伴、无法请求医疗的囚犯。

### 5. Child 债役与智慧 pet

狼族把自己提升的年轻文明称为 Children，并要求其偿还技术、教育和接触成本。最早一批成功提升的 Children 历经漫长世代仍未被宣布还清，说明债务不是短期重建合同，而是可永久延续的从属关系。数十颗行星的 Children 为帝国开采资源，帝国却刻意不把其中许多群体提升到与狼族相当的知识水平，防止其挑战统治。

这种压制反过来造成狼族衰落。机器不能真正产生全新的思想，智慧人口才是技术与文化创新来源；帝国既依赖 Child 劳动，又拒绝让他们充分学习，最终在技术、资源和 Sibling 影响力上落后。改革派主张把旧债视为已经偿清、完整提升 Children、承认平等智慧并修复外部关系。

**Pet** 是同一等级观在宫廷日常中的缩影。智慧外星人可通过合同成为贵族财产，陪同主人公开露面、参加会议、接受抚摸与项圈控制、跪坐脚边并在主人吃完后取剩食。其价值不在于做机器已经能够完成的杂务，而在于展示主人拥有罕见智慧种、外交资源和教化能力。Pet 可被转让，合同能规定是否承担性服务；本人未必参与签署或被提前告知。

狼族语言会区分 pet、servant 与 slave，实际权利却可能高度重叠：需要许可发言，行动受门禁，劳动由主人决定，身体亲密无法自由拒绝，法律人格依附于所有者。并非每位主人都会虐待 pet，私人感情也可能真实存在，但善意不能消除制度性的所有权。

### 6. 阶级、资源与经济结构

帝国资源来自本地矿场、Ancoris、Lux 以及分布银河的 Child 世界。交易、提升债务、合同、王室资金和城市预算均存在，经济显然包含可计价信用与所有权；现阶段唯一能确定的是计价与支付制度存在，具体通行货币名称并未公开。

首都皇室可享用 Parent 级装置、定制疫苗、无人机、私人飞船和自动餐饮；外城与乡村连基础免疫、公共交通和可靠医疗都可能缺乏。阿达斯特拉的衰退不是所有技术突然消失，而是高技术锁在少数地点、跨星供应断裂、地方价值被抽走且公共服务跟不上。

地方经济呈明确分工：Lux 提供天然资源，Tricelli 精炼分配，Ad Rotae 经营娱乐旅游，Lupas 生产文化与政治话语，Adastra City 集中官员和国家管理。分工使各城相互依赖，也让任何一城的罢工、骚乱或分离都能成为帝国危机。

### 7. 教育、档案与知识控制

皇室候选人从小接受数学、文学、历史、战争史、修辞、舞蹈、冥想、摔跤与 pugnu 训练；导师可用教鞭敲打错误者。教育的目标是塑造能公开表演、统治和战斗的贵族，而不是培养专门技术人员。

**Varro’s University** 位于首都区域，是帝国精英学术中心。校规禁止性行为，校园却充满政治组织、教师派系与秘密文献。学校保存受限图书馆，少数获准者可阅读克米扬史家 Hatherhotep 对阿达斯特拉正史的反论，但往往必须写文章证明所读内容“虚假”。战争期间，帝国毁掉境内含克米扬语言的书籍与媒体，使后来出生的克米扬师生几乎无法在阿达斯特拉学习母语。

中央 **archive** 不是纸质书库，而是悬浮的巨大蓝色发光球，表面有蜂巢纹和旋转字符，入口前立着两座张口石龙。它既储存文明、物种与行星 profile，也是 Romanus 仍通信时的 Parent 终端。皇帝传统上垄断对终端异象的解释权；大众信仰与统治者掌握的宇宙战略因此长期分离。

### 8. 媒体、政治表演与谣言

无人机直播、巨大屏幕、Nexus 新闻、偷拍视频和全国同步节目把帝国政治变成持续表演。候选人到城市和乡村演讲，以到场人数衡量势头；五十万人的首都集会足以成为继位合法性信号。Trial、处决和 pugnu 都能被包装成国家叙事。

信息控制同样强大。皇帝可关闭网络，中央可剪辑 Trial，地方派系可上传偷拍，奥莫法间谍可用植物中继绕过官方通道。谣言不必完全虚构，只需给事实更换动机：一次对食物的生理不适可从“外宾不习惯”变成“克米扬鄙视本地文化”，再变成“皇帝带敌人羞辱城市”。在积怨深的地区，传播速度比调查结论更能决定街头现实。

### 9. 信仰、神话与国家身份

狼族公开信仰把 Romanus 视为神圣 Parent，并保留诸多更古老狼神形象。皇帝是唯一被允许正式通过 archive 与 Parent 沟通的人，宗教解释权因而与国家权力结合。断联时，旧式 somni 熏烟和冥想会重新流行：白烟带樟脑丸或刺鼻化学气味，引起咳嗽、呕吐、震颤、血眼、空间拉伸与恐怖幻象。药物通常只制造失控体验，Monitor 却能在特定时机利用这种开放状态把多人拉入共享意识空间。

最重要的国家神话是 Drusus 与 Meera。后世舞剧宣称，梅拉身患绝症，Parent 迫使 Drusus 在救爱人与让帝国繁荣一万年之间选择；Drusus 本想救她，梅拉却自杀，把帝国未来变成唯一选项。可以确定两人真实存在、梅拉死亡、Drusus 随后恢复外向路线；疾病、二选一和具体爱情对白都属于经国家艺术强化的神圣叙事。

“Adastra”本身意为面向群星的政治承诺。Drusus 宣告新名后，狼族不再只是一颗卫星上的孤立种，而把寻找 Children、连接 Sibling 和最终走向银河之外当作国家存在理由。后来的孤立主义不是回到无色的中立状态，而是背叛或重新解释这个已持续约一万年的身份。

### 10. 饮食、浴场与日常礼仪

正式早餐常在卧榻围桌的宴饮厅进行。主人居软榻，pet 跪坐地面，四只小盘可分别盛面包、气味强烈的白奶酪、橄榄和烤禽，再配红酒。狼族用爪手撕肉，日常饮酒量对其体型未必造成醉意。湖岛野餐常见肉奶酪卷、盐渍冰黄瓜、小咸派、果馅点心、酒与 **virdi**——一种冰冷、绿色、带明显蔬菜味的饮料。

公共矿物浴场兼具清洁、休闲和外交功能。狼族可在蒸汽、热池和按摩中讨论政治，pet 传统上帮助洗毛、梳理、上香和披斗篷。Lux 的天然硫泉被视为更纯正的原型，皇宫浴池会复制其矿物配方。身体照料、亲密接触和权力礼仪彼此重叠，不能按地球现代私人浴室习惯理解。

阿达斯特拉存在节庆、舞剧、竞技、度假与大众娱乐。全月可为重要 Trial 停工观看；Ad Rotae 以大型游乐设施和表演吸引游客；pugnu 既是体育也是政治语言。日常文化并不只有军国主义，但力量、戏剧性和公开人格几乎渗入每种高可见度活动。

### 11. 语言、婚姻与新文化输入

狼族没有为自己的通用语另起专名，只称其为 **the Language**。其语法与词汇同地球拉丁语高度接近；拥有拉丁语和意大利语基础的人类可在数月内掌握有限口语与书写。Lingua 让初次交流像听配音，意义先于真实声音抵达；学习原语后才会听见狼的实际发音、节奏和未经转换的文化层次。Language 与拉丁语的重合，是 Romanus 将狼族文化置入地球的直接语言学痕迹。

改革前，妻子不能自行向法院申请离婚，必须由丈夫发起。Amicus 已推动允许女性直接请求法庭解除婚姻。同性婚姻与跨物种婚姻在旧法中均不成立，男性外族伴侣也没有现成皇室头衔；新政府计划先建立法律基础，再以 **Emperor Consort** 容纳男性、非狼族的皇帝配偶。

狼族传统婚姻更强调政治与实用联结，浪漫求婚不是必要核心。人类的下跪、戒指和牵手礼仪进入皇室后，成为有意识的跨文化移植。深蓝星空与银色环线构成的 stretch ring 象征即使分处遥远距离仍保持联结；其所借用的“宇宙如膨胀球面、朝相反方向最终相遇”只是浪漫解释，不是已证实宇宙形状。

**Lover’s Day** 庆祝所爱与珍视之人，重点是结伴外出享受一天，并不以交换礼物为传统核心。花束可被作为人类新习惯加入。皇帝原则上没有真正休假；关闭通知会错过使团、council 与紧急政务。深夜商铺也不会因皇帝迟到数小时而无限营业，显示服务人员仍有自己的工作边界。

Com 曾在地球短暂停留时保存 Marco 的部分 Nexus 食谱，新政府据此尝试在首都开设人类餐厅。第一批只复制意大利饮食，最先尝试 Neapolitan pizza；本地原料不同，厨师必须使用近似替代。它只能代表地球饮食中极小的意大利样本，不能被称作完整“人类料理”。

### 12. 新政府的社会改革

政变后，Virginia 成为 chief advisor。女性初次进入该职位遭到阻力，数月后公众逐渐习惯，但政敌仍以“依靠性关系换取效率”等谣言色情化其权力。她负责为北方小 provinces 争取资金，证明主要城市之外还存在代表权更弱的小型行政区。

Cassius 计划担任 **Chief of Social Affairs**，负责金融、社会与医疗保障，主张联盟带来的财富先覆盖 Triumvir Cities 之外的贫困人口，而非再次被首都精英取得。他在中毒康复后巡视贫困地区；Alexios 在高安保软禁和断绝 Omorfa 通信的条件下随行。全国媒体则迅速把真实夺权战改编成戏剧，用戴人类面具的小狼扮演 Marco，把他包装为“忠诚却未开化的高贵野蛮人”。受欢迎并没有自动消除物种歧视。

## 八、克米亚：政治、历史与社会

### 1. 法老、维齐尔与王室

克米亚最高统治者为 **pharaoh**。**Vizier** 掌握极高行政、安保和外交权限，并通常被外界视为继承人。王室已知同辈包括长女 Henut、Ramoses、Neferu 与幼女 Aya；王族并非自动获得最高大学录取，也并非每位成员都走同一种政治路线。

现阶段法老至少一年未公开出现，可信近况中断约两年；Neferu 本人约三年未见父亲。Ramoses 对外声称法老在银河旅行、近期访问 Omorfa，但当地消息无法印证；他以维齐尔身份实际主持与阿达斯特拉谈判，并不断推迟会面。法老究竟在执行秘密任务、失去行动自由、主动隐身还是已经遭遇危险，仍未得到确认。

Ramoses 的系统权限足以覆盖访客下达的 Ahm 隐私指令，也能掌握秘密 contact room 中发生的部分情况。克米亚法律却规定连法老也不得监听私人房间，外交使团享有豁免，公民有权批评统治者。因此宫廷监控若存在，属于权力越界和政治危机，而不是法律正常授权。

### 2. 从水王国到统一国家

克米亚古文明诞生于极区融水带。水决定农业、城市位置和军队生存，各 **water kingdoms** 围绕河流、融冰与储水长期战争；横越干燥赤道曾像离开本世界。Aarum 是其中最强国家。

阿霍特普统一把多个水王国、物种与区域合并为克米亚共同体。统一时间比阿达斯特拉完成同类整合早约五千年，并因行星面积巨大而经历漫长外交。克米扬历史强调统一主要由谈判完成；无论过程中是否完全没有暴力，现代国家确实把“以语言而非拳头解决冲突”塑造成核心政治美德。

克米亚数千年前便停止为王室兴建极端奢华的新纪念物，转而维护古建和 babekhen。国家权威因此不只表现为不断建新巨构，也表现为让古代水文明、Kemetarian vision 和现代能源工程连续存在。

### 3. Sahira 与技术独立

Sahira 是克米亚史上最有效的反 Galaxias 分离主义者。她没有让国家真正退出 Galaxias，却促成摆脱 Parent 技术依赖的工程：克米亚从只能使用遗产，转向自己设计、制造、改进和供能。Sahira’s Tower 以她命名，正体现其遗产被国家吸收后的双重意义——政治分离失败，技术自主成功。

现代 **Children of Sahira** 继承反 Galaxias 和反阿达斯特拉思想，却采用针对本国人的恐怖手段。Neferu 青年期曾利用王室渠道盗取资金支持该组织，间接造成数十人伤亡；事件被法老掩盖后，他先遭秘密监禁，再接受五年阿达斯特拉语言与历史训练，最终被派为战争后一百多年首位踏上阿达斯特拉的克米扬。这项安排同时是惩罚、改造、赎罪和外交投资。

国家使用 Sahira 的技术遗产不等于认可 Children of Sahira 的暴力。反 Parent 依赖、反 Galaxias、反狼族与恐怖主义是可以重叠却不相同的立场。

### 4. 法律、公民权与庇护

克米亚禁止拥有智慧 pet，并承诺接纳逃离狼族压迫的任何 creature。王子可在紧急外交情境中直接授予外来者公民权，这种权限能救人，也说明王室仍可绕过通常应由当事人参与的程序。

公民有批评法老的权利，私人房间受法律保护，外国使节拥有外交豁免。王权强大但不是公开宣称无法律边界。维齐尔以监禁、监听或 espionage 指控威胁客人，会在国内遭遇合法性问题，法老回归后也可能撤销其决定。

Ahm 的 privacy 属于政策权限而非物理断网。系统即使“退出”，仍能听到恢复服务的口令；更高权限者也可 override。这使克米亚隐私法高度依赖掌权者守法和审计，而不是依赖个人能够完全切断设备。

### 5. 教育与知识文化

**Sabayet** 被称为 Galaxias 最优秀的大学。录取原则是 merit，王族也会申请失败；财富和家庭地位能提供更好准备，却不能自动换取席位。父母与多名王室成员曾入读，Ramoses 多次落选，成为其私人地位与国家继承预期之间的裂痕。

克米亚大学的性与身体规范比 Varro 开放，校园甚至设有专供性活动的房间。学术价值更重知识能力而非禁欲表演。对狼族历史，克米扬史家会逐章撰写反论，指出删节、战争宣传和被消失的受害者。Hatherhotep 的《The Price of Metal》记录狼獾历史，在阿达斯特拉发行的删节版本中被整章移除。

Khemian 语言对狼族发声结构和听觉习惯极难，书面流利者也可能因口音让 lingua 无法识别。语言学习因此是一种重要外交劳动。完全说出克米扬句子的狼会获得远超普通礼节性翻译的认可。

### 6. 友情、性、承诺与心理健康

克米扬朋友会拥抱、靠头、握爪、共同睡眠并帮助彼此承接精神痛苦；身体亲密不自动意味着恋爱或性。不同性别都可成为伴侣，性角色的表达也较开放。狼族常把这种距离误读成恋爱，克米扬则认为狼族朋友间过度疏离，迫使个人独自处理创伤。

**Ahewawi** 意为“旧痛”，指持续、复发并影响当下的心理创伤。它不是天赋、神谕或软弱，而是可被识别、治疗并由关系支持的状态。克米亚对 psychosis、dissociation 和创伤有区分与转介资源；跨层面训练前也会先筛查这些状况，以免把内部症状误认成 Parent 接触。

克米亚外交重视承诺。一个国家即使因时代变化无法履约，失信也会破坏一代人的关系；公开暴力则被视为无法控制自己的软弱。所谓“Khemian bluntness”不代表他们从不隐藏：礼貌、停顿、讽刺和潜台词同样能包装敌意，只是理想中的冲突应靠言语与长期责任解决。

### 7. 宗教与日常感官

**Ahhotep** 是常用于祝祷和惊呼的神圣名字或概念，正式欢迎可祈愿其与客人及阿达斯特拉同在。Sakhaet 制度从 Ahhotep 统一后延续，说明宗教、国家记忆与跨层面职责紧密相连。

王宫以草本、香料和 oliban 类 incense 塑造气味，沙漠热风与干尘从庭院进入；室内纳米材料又吞掉脚步、衣料和远处谈话，使人产生压迫性的寂静。水声房间、悬浮喷泉和饮水限制同时提醒访客：在这个文明中，水既是古代战争根源，也是最高技术与礼仪所反复展示的安全感。

饮食包括极辣禽肉菜 **Dakhet en-Shemau**，也使用 papywei 处理疼痛、晕动和心理负荷。飞船循环空气略带陈旧金属味，过滤系统会很快清除烟雾；储水有限，洗手有定量上限，也提供无水消毒。即使是高度先进的克米亚，资源循环仍遵守物质限制。

克米亚一日约二十二小时，宫廷常把第十七小时作为晚餐时间。正式使团会围绕早餐、晚餐和内部会议重新安排作息。传统热地服装以布料从腿间绕过大腿、在前方以装饰扣固定，现代内衣和王室礼服也可并存。正式迎宾会先按头衔致意，再互祝 Ahhotep 与来客及故乡同在；站位、等待时长、面具是否抬起、谁先开口都具有政治含义。故意让外宾在烈日下等待，本身就是以环境表达地位。

## 九、跨文明关系、战争与当代势力

### 1. 阿达斯特拉与克米亚

两国冲突不是单纯的狼族与豺族仇恨。克米亚是多物种国家，战争涉及的是提升权、资源、探索主权、Child 待遇与谁有资格代表 Galaxias。阿达斯特拉强调附近世界和旧勘探权属于自己的势力范围；克米亚则把已经被狼族放弃的文明视为仍可救助、提升的生命。

两国至少发生过三次战争。第二次战争中，塔哈拉狮族援助克米亚。第三次战争由德萨雷斯大屠杀触发，发生于 Potes 在位、Cato 任 Imperial Legate 的时代，距当代已超过一个世纪。狼族叙述把战争称为平局，并将 Cato 记为阻止全面败北的人；同一叙述也承认 Khemia 具有技术优势。Wolf 官方后来把“没有败亡”包装成胜利，但没有中立结论能够判定决定性胜负，也没有证据显示 Khemia 曾因主动克制而放弃毁灭 Adastra。

战争使狼族与几乎所有 Sibling 关系断裂，引发持续约两至三百年的衰退。克米扬社会则保留屠杀、疫情和失信记忆，把联盟视为必须由阿达斯特拉先承担责任的长期工程。Neferu 被派往阿达斯特拉后，两国才重新建立持续在场的王室通道；Amicus 登基后又把正式联盟列为 Parent 任务的第一步。

联盟的共同利益包括恢复 Galaxias 合作、让阿达斯特拉重新接入星际运输、保护 Children、交换技术并应对更遥远危机。阻力则来自狼族分离主义、克米亚 Children of Sahira、两国战争受害者、奥莫法难民群体、法老失踪与对真正利益交换的猜疑。

### 2. 德萨雷斯大屠杀

阿达斯特拉先行探索一颗距本土约五十七光年的星球，将其判定为缺少有希望的智慧生命。克米亚随后以贵金属购买独立探索权，不到两个月便在地下发现原始狼獾，并开始长期 uplift。突袭发生前，狼獾已经形成住宅、学校和育儿设施，成为能够延续自身的社会。

Potes 后来把克米亚在近邻提升新文明视为主权侵犯，没有先重开谈判，而命亲信 Cato 发动突袭。燃烧武器摧毁聚居地，超过五百名克米扬和十三万五千名已提升狼獾死亡。数月后 Wahneferhotep 率救援队进入焦黑废墟，只找到两名仍活着的狼獾。

Brunis 是这两名幸存者之一，灾难发生时年龄太小，只留下有限直接记忆。他后来在克米亚获得照料与教育，使用义肢，成长为驻阿达斯特拉大使。其完整政治、语言与谈判能力本身证明 uplift 成功，也让“清除克米亚罪行、没有更多流血”的狼族旧叙事无法维持。

德萨雷斯也说明地下生态为何会逃过轨道或地表勘探。先到达、先命名或离得近，都不能赋予文明对未被自己发现的智慧生命之所有权。以漏判为基础的势力范围，不足以否定后来发现者的保护责任。

克米亚统一史把狼族首次勘察并放弃该世界记在统一后第 15,324 年，把克米亚开始重新勘察记在第 18,342 年；复勘后两个月内，地下狼獾被发现并进入提升。反论史把提升至突袭的间隔记为约二百年，较晚的克米亚学术谈话却又把狼獾发现概括为约一百五十年前，两项相对年代无法同时指向同一发现节点。确定的事件顺序仍是：狼族漏判并放弃——克米亚购得探索权——发现地下狼獾——长期提升形成社会——Potes 与 Cato 突袭——第三次克米亚战争——两名幸存者进入克米亚。

### 3. Lucius fever 与疾病政治

战争期间，阿达斯特拉女性 Antonia 被克米亚俘虏。她是 **Lucius fever** 的无症状携带者，随后暴发的疫情造成数十万克米扬死亡，超过任何一场单独战斗带来的损失。阿达斯特拉校园把她塑成女间谍并立像纪念；她是否有意利用病原、是否知道自己的携带状态，却没有得到确定结论。

这一事件与 avia pox 共同证明，跨文明接触中的病原可以比武器更致命。无症状携带者会被敌对国家解释为生物攻击，受害方的疫情记忆又会跨越数代影响外交。检疫失败不只是一项医学疏忽，也可能引发战争、退出谈判和对整个物种的污名化。

### 4. 阿达斯特拉与奥莫法

狼族与奥莫法猫族至少打过三次战争。第三次战争惨烈到 Romanus 与 Galenians 共同违背最低干预原则：阿达斯特拉一方的 Stretch drives 失效，狼族天空出现古老神祇征兆和要求和平的信息，克米亚随后促成停战。奥莫法一方的驱动是否同时失效并未说明。Parent 的纽带阻止了战争继续升级，却没有消除战后敌意。

当代奥莫法主流把阿达斯特拉视为 Galaxias 稳定的最大威胁，一些势力要求取消其 Sibling 地位甚至逐出体系。奥莫法情报人员 Alexios 借 pet 合同和与 Cassius 的亲密关系进入皇室，任务以 **Chaos** 为名，目标是制造政府与社会不稳定。他泄露、操控或放大宫廷矛盾，对 Cato 危机和后续骚乱负有重要责任，事后获得配备 Stretch 的飞船作为奖励。

Alexios 后来与 Omorfa 失联并受阿达斯特拉监控，仍尝试重建植物通信器。Cassius 在 Omorfa 又遭事实软禁，偷走该飞船返回，警告当地势力正等待阿达斯特拉内乱与其他行动配合。可以确认奥莫法存在趁权力空缺施压的计划；它是否与辛多、克米亚王宫、Lupas 资金和所有分离运动属于一个统一阴谋，仍未得到证明。

克米亚约居住二十万奥莫法人，许多是第二次阿达斯特拉—奥莫法战争后形成的世代难民。该群体原本不少人支持和平，阿达斯特拉联盟启动后却迅速出现大规模抗议。难民历史、奥莫法本土政治与克米亚内部动员在这里相交，使“克米亚是否支持联盟”不能只由王室态度代表。

### 5. 辛多与塔哈拉

辛多曾在梅拉时代帮助约束狼族，效果却比 Parent 预计短。现代辛多已与阿达斯特拉完全断交，也保留自己的 Parent 沟通传统。Virginia 怀疑辛多与其他反狼势力有所协调，但目前只有同时出现的敌意与行动迹象，不能把怀疑当成同盟事实。

塔哈拉与克米亚是稳定盟友，Parent 谱系也有古老亲缘。其技术在 Galaxias 中位居前列，曾直接帮助克米亚对抗狼族。塔哈拉的 dakhur 与克米亚 sakhaet 建立私人跨层面联系，说明正式外交之外还存在不受普通通信距离约束的精英意识网络。

### 6. 地球整合任务

人类整合由 Marco 返回地球后承担，预计约八年。任务不是公开宣告外星统治，也不是立即把全人类放入单一政府，而是在尽量少泄露高阶真相的情况下让彼此竞争的国家建立可持续共同机制。美国、英国和欧洲政治机构已参与接触，Marco 是主要桥梁，却不能代替地球所有社会作决定。

任务开始约两年后，avia pox 造成七名外交人员死亡，Marco 被隔离，美英威胁退出，谈判暂停。Parent 对一名 Human／Earth 关键个体的观测显示，成功 unification 概率从 22.581% 降到 12.554%，在某次未指明的“arrival”前完成 full unification 的概率仅 0.00000011%，相关路径从 Beta 降为 Zeta 并转入最低观察。这个数值描述的是当时的概率状态，不是命运判决；“arrival”是否指 Other 主体也尚未被明确命名。

地球危机与狼族—克米亚联盟互相依赖。若阿达斯特拉重新获得 Sibling 信任，地球便有更安全的医疗、翻译与外交入口；若人类整合成功，Galaxias 则得到一个已在单一世界内部融合多种 Sibling 文化的新型成员。

### 7. 当代复合危机

Amicus 离开阿达斯特拉亲赴 Khemia，预计至少数月，若进展顺利可能超过一年；Virginia 摄政，Cassius 回归协助。国内同时面临 Senate 失序、Lupas 要求男性共治、Lux 旧怨、分离主义暗杀与奥莫法可能行动。皇帝不在场会让每座城市重新衡量服从中央的收益。

克米亚一侧，法老长期缺席，Ramoses 实际执政；使团抵达前一日发生与 Children of Sahira 相关的机密事件，奥莫法群体抗议，宫廷疑似非法监控。Ramoses 一面宣称终身支持联盟，一面反复延迟会面、刺激使团并威胁 sakhaet 与狼族访客；使团成员怀疑这些行为带有蓄意施压成分，其真实目标尚未清楚。

使团抵达第二日夜间，Amicus 已决定若三日内仍见不到法老便离开并放弃联盟。次日原计划进入 Khemen，由皇帝向公众演讲。Aya 与 Scipio 刚发现 Parent 的概率视角和 The Leaves 威胁，Neferu 准备调查兄长，各方仍未共享全部情报。法老仍未现身，联盟最后期限正在倒数，The Leaves 的性质与王宫权力异动均未解决。

## 十、全景编年史

### 一、编年基准

阿达斯特拉的一日由十九个小时构成，克米亚的一日由二十二个小时构成；Earth 所用日制与两者均不相同。Lingua 会把时间概念自动换算成听者最容易理解的尺度，因此跨文明记录中的“日”“月”“年”只保证相对长短，不能与 Earth 历法逐分逐秒等同。Marco 抵达 Adastra 的年份定为“皇位危机元年”。明确标注“当日”“次日”“三日内”或具体小时的事件构成连续日序；“两周半”“一个 Adastra 月”等时间保持原文明尺度，深远年代亦保留各文明纪年。

Galaxias 中不同文明的战争编号各自独立。“阿达斯特拉—克米亚第三次战争”是狼族与克米亚之间的第三场大战；“阿达斯特拉—奥莫法第三次战争”则是狼族与猫族之间的第三场大战。两个“第三次”只表示各自在不同双边战争序列中的次序，彼此既非同一战争，年代也不因此相同。

### 二、深时史：生命起源、Parents与宇宙威胁

#### 1. 已知生命的共同源头

在通常物理宇宙的这一侧，已知生命来自同一原始源头。不同天体相隔数十、数百乃至数万光年，仍会演化出可相互对应的生态位与身体结构：Wolves、Khemians、Omorfans、Hindos、Taharkans、Humans，以及鸟形、熊形、狼獾形等智慧生命，都能在彼此世界找到近似的骨骼、感官、情绪和生殖结构；植物、鸟、昆虫与蛛形生物也会出现遥远的相似性。跨世界的相似并非各星球独立重复同一奇迹，而是共同起源在不同环境中的分化。

这一共同起源之外还存在异质事物。Khemian古老传说把它称为The Other：它近似机器、病毒或生命边缘的过程，自身不像普通sapient那样思考，却必须依附sapient意识才能维持或增强存在。传说认为它每隔数十亿年扩散一次，在宇宙这一带约已来过半打，每轮退去后都会留下稀薄而斑块化的残余。弱小残余能附着于物体、穿过智慧生命、借宿主的记忆与恐惧投射鬼魂、怪物和不合逻辑的异象；宿主对投影的反应又会成为它继续存在的养料。

周期次数与远古规模仍主要保存在Khemian传说中，但The Other的当代存在已经不再只是民俗。Marco在Varro大学看见星球死亡、恒星枯萎、黑色触须蔓延和雕像颈部瞬间扭曲；这些异象与他后来遭遇的、呈Meera形貌的拟态高度相似，但Monitor只明确确认后一次入侵来自The Other。已确认的投影能从宿主想象中取出最可信的形貌和语言，放大宿主原有疑虑，却不能成为完全独立的思想者。数年后的The Leaves同样以干叶摩擦声出现，能借私人欲望诱导并伪装成可信人物，而且在四个保留跨位面传统的Sibling文明中均有记录。它与The Other的已知表现高度相似，显示同类意识威胁已经进入Galaxias日常；两者是否为同一存在，尚未得到Parent、Monitor或sakhaet体系的正式确认。

#### 2. Parents跨越银河的时代

Parents来自本银河之外，掌握Siblings仍未理解的跨银河航行方式。它们进入银河后传播各自的文化，从本地候选智慧物种中挑选最有潜力者，使其成为Siblings，再让Siblings寻找、提升并教导Children。当前仍有八个Parent存在或Parent谱系留在银河，但它们极少直接与下层文明交流。它们并非全知全能：其心智能同时处于多个时间位置，从侧面观看大量可能性，却会预测失败；每一次直接干预还会改变后续选择，使未来更难读清。

Romanus选择Wolves，Galenians对应Omorfa的Cats，Kemetarians对应Khemia，Kushari对应Taharka。Romanus与Galenians在抵达本银河以前便来自同一外部银河，关系极深；Kemetarians与Kushari则拥有同一更古老的uplifter，在分别迁徙数十万年后于本银河重逢并建立亲密联系。Parent之间因此并非没有亲缘、情感和立场差异，它们也会因所关切的Siblings相互残杀而破例介入。

Parents与普通物理平面之间存在隔层。Monitor被设计成两层之间的桥梁，负责接收指令、观察Galaxias并在许可范围内与sapients对话。Parent平面内的时间相对物理世界近乎静止，身体可表现为心智构成的形体；Parents能够读取记忆、展示未来分支、控制Lingua、暂时借用身体发声，并在死亡不久、身心仍可回收时重建严重损伤。它们能修复Cato残毁的视觉系统，也能替换Marco被割开的气管和声带，但这种力量不意味着它们愿意普遍救治每一个生命。

#### 3. Galaxias的长期工程

Siblings长期把提升Children理解为一场彼此竞争的竞赛，以扩张疆域、资源和从属文明证明自身优越。Parents后来明确否认这种理解：竞争从来不是终点，真正目标是让Sibling与Children共同达到Parenthood。其硬性标志不是统治更多世界，而是实现可实用的跨银河航行。Stretch Drive足以穿越本银河内部的遥远星区，却无法为跨银河距离积聚所需能量；单一物种也难以独自跨过这道技术门槛。Khemians从最早期Galaxias史中得出结论：只有整合全银河智慧生命的知识与能力，才能完成升格。

这项工程在狼族时代已经持续约两万年。Parents愿让Galaxias尽量靠自身选择成长，只在路线严重偏离时告知极少数关键人物。它们的最终准备对象是The Other：那个异质过程正在宇宙边缘扩张，许多千年后将与Galaxias发生必须正面处理的相遇。Wolf—Khemian联盟、各Sibling停止内斗、Human融入Galaxias与跨银河技术，都是这场遥远危机的前置步骤。

#### 4. Earth实验与多轮接触

Earth并非真正从未接触Galaxias。Wolf、Khemian、Hindo、Bear、Lion、Ram及其他Sibling文化都在Human文明中留下过成分，地球上分布于不同时代与地域的拟兽神祇和文化形象是这些介入的残痕。多个Siblings曾尝试提升Humans，随后又先后放弃；Earth最终失去了关于外星智慧生命与Galaxias的完整记忆，依照星系法，再次接触时会被视为新的First Contact。

Parents把Earth塑造成experimental microcosm：让多种Sibling文化进入同一尚未接受正式uplift的物种，观察Human是否能把相互冲突的传统融合成独立文明。Human依靠自身发展到原子能、航天、全球Nexus与复杂国家体系，使实验被判定成功。Human因此不会成为任何既有Sibling的Children，也不会归Wolf、Khemian或其他文明所有；其地位是独特的Sibling-like level，只在Parents之下接受整体融入安排。

### 三、Khemia与Adastra的上古文明史

#### 1. Khemia的水之王国与Ahhotep统一

Khemia在统一以前并不是单一种族或单一国家。行星大部分区域酷热、干旱，文明最初只能依赖两极附近稳定融水，在极区边缘建立water kingdoms。Aarum是这些古国中最强者。水源决定农业、人口与军力，古国之间长期为水交战；在缺乏行星级交通的时代，从一极横越干旱赤道前往另一极，几乎与后世星际旅行同样难以想象。

Ahhotep’s Unification结束了水之王国时代。Khemia面积巨大，统一过程比Adastra的后世统一更漫长，却主要以外交、承诺和共同制度完成，而不是靠单一王国彻底征服所有对手。Khemia比Drusus统一狼族世界早约五千年，因而其统一历史已延续一万五千年以上。Aya是统一以来第八十三任sakhaet；职位常为终身制，也曾空缺或由在世者交接，平均任期超过一百五十年。

统一后的“Khemian”是公民与文明身份，而非jackal的同义词。国家由十五个物种构成，jackals占总人口六成以上；Brunis证明狼獾可进入最高教育与外交机构。约二十万Omorfan居民是否计入这十五个物种并未说明。Pharaoh居于国家顶端，vizier掌握极高行政权并通常被视为继承人；公民依法有权批评pharaoh，连pharaoh也不得监听私人房间。Khemia逐步把古代水利、行星改造、能源、教育和跨物种公民权整合成共同国家。

#### 2. 纪年不详：Ahhotep统一后的Sahira技术独立运动

Sahira是Khemia历史上最成功的反Galaxias分离主义者之一。她没能让Khemia脱离Galaxias，却推动文明摆脱对Parent技术的单向依赖。此后Khemians不再只是维修Parents赠予的机器，而能建造自己的Stretch飞船、发展Ahm并建立行星级能源系统；Lingua核心仍未被完整破解。赤道上的Sahira’s Tower从恒星汲取能量，再以橙粉色能束送回地表，承担整个行星的能源核心；Khemia也由此有能力改造大气和环境，把原本局限于极区的文明扩展到整个行星。

Sahira的政治遗产后来分裂成两层：国家接纳其技术自主，却不接受暴力脱离Galaxias；Children of Sahira则继承分离主义并以恐怖手段袭击本国人。两者同源，却不等同。

#### 3. Wolves被Romanus选择：约两万年前

约两万年前，Romanus从约一千个候选物种中选中Wolves，将其提升为Sibling。狼族获得Lingua、Stretch、Archive、Com、高级无人机与医学等Parent技术，开始寻找并提升自己的Children。帝国把提升成本变成Children必须偿还的“债务”，并把契约延续到首批Children在万年后仍未还清；同时故意不把部分Children提升到与Wolves相等的智力，以便维持控制。

#### 4. 第一次抛弃：约一万五千年前

约一万五千年前，Wolves拒绝Romanus，成为第一个abandoned Sibling。与Parent断开后，狼族失去Children、资源航路和多数Sibling关系，月球上的政体重新陷入缩小、分裂与荒芜。此后约五千年被后世概括为Time of Matr或Pre-Adastra时代。各地小王国与早期统治者并存，政治比后来的单一皇统更破碎；女性也曾统治部分小国，但后世父权史观把即使繁荣的女性政权也改写成淫荡、疯狂或残酷。

#### 5. Drusus与Meera：约一万年前

约一万年前，Drusus推动狼族重新联系Romanus，并与Hindo雌虎Meera建立深刻关系。Meera最终自杀，Drusus继而重整狼族国家，把月球与帝国命名为Adastra，意为面向群星的新秩序。他建立的外交礼仪和皇统框架成为此后一万年的政治基础。

后世舞剧把这段历史塑造成一场神圣二选一：Parents 要求 Drusus 在拯救 Meera 和换取帝国一万年繁荣之间选择，Drusus 想救爱人，Meera 以自杀替他选了帝国。Drusus、Meera 与她的自杀都是真实历史；她的疾病、两者关系的程度、Parent 是否确实提出过这项条件以及她的自杀动机，均未得到确认。“爱人或帝国”的完整形式属于狼族千年间不断浪漫化的国家神话。

Drusus以后，Wolves重新找回失联Children，恢复与Siblings交换知识和财富，并把对外扩展称为Ad Astra政策时代。帝国在银河数十颗Child世界取得资源，却把开采与劳役包装成提升债务。外向政策带来长期繁荣，也让皇帝成为唯一正式接触Romanus、分配Stretch资源和解释Parent意志的人，宗教权威与政治权力由此合一。

#### 6. 一万年皇统中的长期裂缝

Drusus以后的皇统比Time of Matr易于追踪，却从未成为和平直线。数千年间反复出现宫廷夺权、生死决斗、公开处决、疯狂君主与主动退位者。地方主要城市逐步由民选triumvirates治理，中央皇帝则保留放逐、处决、关闭信息网络和裁决地方权力的强大能力。Lux曾为独立城邦，也曾再次脱离帝国；当地罢工和骚乱多次切断全月工业，并与若干皇帝的失败甚至死亡相伴。

受禁的跨文明史书声称，Lucius恢复过火刑，并会处死被怀疑嘲笑其不育或性能力者；同一史学传统还记载，数世纪前某位皇帝曾向Lux大量输入烈酒，企图磨灭当地的反叛性格。阿达斯特拉通行皇史没有保存这两项政策，当代皇室成员也不知情，因此它们属于尚未被共同史学确认的黑暗记录。Vitus在约一个世纪前出售或分发皇宫贵重装饰，使首都皇宫改为相对朴素、实用的形象；其孙辈时代的Lux皇家别墅反而比首都宫殿更奢华。Potes时期，女性才在约五十年前获准与男性一同进入Varro大学主校舍，显示狼族制度改革远慢于其星际技术。

### 四、战争史：两条第三次战争与近代孤立

#### 1. 狼族对外战争的共同模式

Wolves在重返Galaxias后多次把邻近Child、资源权与文化尊严视为帝国主权，以战争回应其他Sibling的提升或安全政策。Omorfa因此把Adastra视为过去一万多年里最经常主动攻击其他Sibling的文明，并长期采用情报与“受控混乱”阻止狼族恢复扩张能力。Khemia则多次在战争后担任调停者，即使自己也是狼族战争的受害方。

#### 2. 阿达斯特拉—克米亚战争序列

第一次阿达斯特拉—克米亚战争的起因、战场与结果没有形成清晰的当代公共年表。

第二次战争中，Taharkan lions 援助 Khemia。Taharka 是 Galaxias 中技术仅次于 Khemia 的先进 Sibling；Kushari 与 Kemetarians 共享更早的提升根系，而 Taharka 与 Khemia 本身又是长期政治盟友。两层关系并存，实际军事援助建立在 Sibling 联盟之上。

第三次阿达斯特拉—克米亚战争发生在皇位危机前超过一个世纪，并与Deshereth屠杀直接相连。它不是阿达斯特拉—奥莫法第三次战争。

#### 3. Deshereth／Quarto-2413b与第三次克米亚战争

Wolf一侧把距Adastra约五十七光年的旧勘察目标称为Quarto-2413b，Khemian反论则把狼獾原乡称为Deshereth。反论把Wolf首次勘察记在Khemian统一后第15,324年，把Khemia重新勘察记在第18,342年；Khemia以贵金属购得探索权后，两个月内便在地下发现具有智慧潜力的狼獾并启动uplift。反论又称突袭发生在提升开始约二百年后，而当代Khemian谈话另有“约一百五十年前发现狼獾”的概括，绝对年代因此仍未闭合。

此后经过一段足以建立住宅、学校、育儿设施和社会组织的长期提升期，Potes才得知Wolf旧勘察遗漏了智慧生命。他认为Khemians在离Adastra如此近的旧勘察区提升狼獾，等同侵犯Wolf主权；他没有先行谈判，而是派Imperial Legate Cato发动突袭。攻击广泛使用燃烧武器，超过五百名Khemians和十三万五千名已提升狼獾死亡。救援队数月后只找到两名狼獾幸存者，Brunis是其中之一，身体留下严重伤疤并使用义肢；他后来进入Khemian高等教育，成为驻Adastra大使和这场屠杀的活证人。救援由Wahneferhotep负责。

Quarto-2413b 与 Deshereth 在距离、参与者、探索权交易、狼獾提升、大屠杀和战争后果上高度对应，极可能是同一世界的双重名称，但两个名称从未在权威记载中被直接认定为同一世界。矛盾的相对年代也无法反推出Potes、Cato与Brunis的确切年龄。

Wolf官方把Cato的行动称为清除违法提升、摧毁Khemian武器基地并和平归来，极少承认Children死伤；Khemian记忆则以烧毁的学校、育儿设施和十三万五千具狼獾尸体为核心。突袭引爆第三次阿达斯特拉—克米亚战争。Khemia拥有技术优势，Wolves依靠耐伤、军队韧性与Cato指挥避免全面败北；狼族把结果包装成胜利，较克制的说法则是没有决定性胜者。Cato在战争中失去一眼和部分颅骨，另一眼后来也失效，Romanus为他安装了机械visor。

战争结束后，大多数Siblings与Wolves断交，Hindo最终完全停止往来，只有Omorfa在很长一段时间继续维持关系。帝国由此进入约两至三百年的政治、经济和技术衰退。Potes时代仍拒绝对Deshereth负责，这笔历史债成为后来Khemian联盟谈判最难跨越的条件。

#### 4. Antonia与Lucius fever

Antonia事件发生于某次阿达斯特拉—克米亚战争期间；所属战争序号与确切年份尚未确定，但必然早于当代联盟重启。Wolf女性间谍Antonia被Khemia俘虏后，作为Lucius fever的无症状携带者引发疫情，造成数十万人死亡，超过任何一场单独战斗给Khemia造成的损失。她是否有意把病原当作武器，始终没有形成一致结论。这场灾难使跨物种病原、间谍活动与战争伦理在两国教育中永久纠缠，也预示Human后来面对avia pox时的危险。

#### 5. 阿达斯特拉—奥莫法战争序列

狼族与Omorfan cats另有独立的至少三场战争。第二次阿达斯特拉—奥莫法战争促使大量Omorfans逃往Khemia；当代Khemia约有二十万Omorfan居民，其中许多家庭已在当地生活数代。

第三次阿达斯特拉—奥莫法战争极其惨烈。Romanus 与 Galenians 因两族古老纽带和战争痛苦同时破例干预：它们让阿达斯特拉一方的 Stretch drives 失效，并在狼族天空投射旧神征兆和要求和平的信息。奥莫法一方是否遭到同样停用并未说明。Khemia 随后把超常停战转化为政治协议并促成和平。这是 Parents 公开承诺尊重 sapient agency 之后最显著的违例之一。

这场“第三次奥莫法战争”的交战双方、Parent 组合、停战方式与 Deshereth 引发的“第三次克米亚战争”全部不同。前者的核心是 Wolves 与 Cats、Romanus 与 Galenians 停用狼方 Stretch 以及 Khemia 居中调停；后者的核心是 Wolves 突袭 Khemian 主导的狼獾 uplift、Deshereth 大屠杀以及 Cato 受伤。公共争论虽常把两者都简称为“第三次战争”，两场战争的参与者、成因、年代与结果却始终相互独立。

#### 6. Potes之死与近代帝位危机前夜

第三次克米亚战争的老将Cato后来成为Potes最亲密的顾问。Potes在Marco抵达约五个月前乘帝王飞船降落Adastra City时坠毁身亡。事故调查发现导航系统可能被经由实体端口植入恶意软件；Cato以acting emperor身份提前叫停调查，参与调查者此后相继失踪。没有找到安装恶意软件者的直接影像，但宫内植入、调查终止、灭口链与Cato随后掌权构成高度完整的政变前史。

Potes突然死亡使长子Amicus来不及按预期完成继承准备，次子Cassius正式挑战帝位，Cato以acting emperor和三场Trials裁判者身份控制过渡期。Romanus在帝位空缺后停止供应Stretch能量，Wolf帝国被锁在Stella Vita恒星系内；分布于银河的Children、资源世界和外交使团随之失联。长期衰退、地方贫困、Lux骚乱、Khemian仇恨与帝位悬空在同一时刻汇合，皇位危机由此开始。

### 五、皇位危机元年：Marco抵达与Adastra宫廷危机逐日史

#### 1. Earth第0日：Roman Forum、非法First Contact与绑架

Marco赴Rome留学的第一天，距离正式开学约两周。他白天游览Roman Forum与Palatine Hill，凌晨约二时乘出租车返回公寓，约四时在闷热潮湿的卧室里遇到Amicus。Amicus已离开Adastra约两日，并因此错过前一日在Lux举行的候选人团结演说；Virginia代他出席。

Amicus原先依据过期资料，把Earth Human当成第五级智能、早已失败并可交易的Child。他打算寻找一个罕见的智慧个体订立pet协议，以此在继位竞争中压过拥有Omorfan pet Alexios的Cassius。当Com接入Earth Nexus后，旧判断立即崩溃：Humans已经掌握核能、航天、黑洞和全球信息网络，Earth却完全不知Galaxias。依照First Contact法，这种“失去Galaxias知识后再接触”的情况必须重新视为首次接触；Amicus没有Parent授权，已触犯足以让整个Wolf文明再次遭抛弃的禁令。

恐惧促使Amicus麻醉、捆绑Marco并将其带上帝王小型飞船。他最初谎称自己执行渐进接触任务、另有Humans也被选中，后来在飞船冲突和Com揭露下承认没有任何官方计划。他在返程中一度被Marco攻击；Marco第一次挥击头部时，武器轨迹被无形力量压低，只击中颈侧，显示Monitor早已在维持既定路线。

返航途中，Marco误触飞船界面，使航向锁定恒星Stella 556425。强引力把乘员甩向舱壁，热盾和外壳受损；两人合力改变航向后脱离光球层，飞船进入recovery mode再恢复。事故既延误回程，也让Marco无法直接以暴力控制飞船返Earth。Stretch所需能量已经耗尽，地球位于这艘船可达范围的边缘，双方只能继续前往Adastra。

#### 2. 到宫之夜：秘密交易成立

飞船穿过Stella Vita系统时，Marco第一次看见绿蓝色Adastra、粉笔灰色Ancoris和白色Torque。Adastra是环绕高重力行星Ancoris运行的宜居月球，Torque是另一颗更小卫星。飞船在闷热潮湿的宫廷机库降落，夜间可听见鸣虫，石廊脚步在大理石与拱门间回响。

Amicus无法把Marco送回Earth，也不能公开承认非法接触。他已在飞船内为Marco安装Lingua，抵宫后又为他伪造来自“Simia”的失联Child身份，并把他带进皇宫。两人达成交易：Marco暂时扮演Amicus的pet，协助其赢得帝位；Amicus一旦成为皇帝，便利用恢复的Parent权限和Stretch资源把Marco送回Earth。Marco由此从未经授权的俘虏变成继位竞争的秘密参与者。

#### 3. 到宫第1日：宫廷结构显现

清晨，Marco从面湖阳台看见粉橙色曙光、森林山脉、湖中小岛和对岸Adastra City。首都人口略超五百万，Wolf总人口约八千万；首都主要容纳官员与家属，银河级技术集中在皇宫，普通地区并未共享同等无人机、医疗和交通。

早餐中，Marco正式见到Cassius与Alexios。Pet被安排在主人脚边、主人先食、pet吃剩食并接受项圈控制，这使Wolf的智慧生命所有权从抽象法律变成日常礼仪。Alexios来自Omorfa，是Sibling个体，却以正式合同成为Cassius的pet；合同禁止体罚，地位仍依附主人。Cassius以传统主义、反Khemian联盟和优先Wolf民生争取支持；Amicus则主张完整提升Children、宣告旧债已清偿并恢复Sibling关系。

Cato在帝位空缺期控制Com、宫廷安保和Trials，却不被帝王飞船承认为正式皇帝。三项Trials被确定为音乐与舞蹈、修辞、pugnu战斗，采用三局两胜。五个地方triumvirate单位与Cato代表的中央单位共同评判，候选人同时继续在城市和乡村竞选。

#### 4. 到宫第2日前后：Neferu留下与联盟议题进入宫廷

Virginia带回Khemian王子Neferu。Stretch Depletion发生时，他正在Wolf势力范围内访问，没有随Khemian撤离船离开，并选择继续推动两国联盟。Khemia是当时最先进的Sibling，已经能独立制造或操作自己的Stretch技术；对被Romanus锁在本恒星系的Wolves而言，联盟既可能提供恢复银河交通的路径，也会迫使帝国面对第三次战争和Children权利。

Neferu公开批评Wolf把Children、servants、slaves和pets分成不同词，却持续支配其劳动、发言和身体。他的存在把继位竞争从兄弟间的人气之争扩大成整个Ad Astra路线是否继续的问题。Cassius主张即使破解不了Stretch，也应放弃外星Children、在本星系自足；Virginia与Amicus认为这会永久切断资源、知识和Parenthood道路。

#### 5. 到宫后的首个约两周：适应、竞选与Meera舞剧准备

随后约两周，Marco适应十九小时日制，学习宫廷礼仪、Wolf历史与舞蹈。Amicus在各城密集演说，民意从明显落后回升到至少达到Cassius的一半以上。第一场Trial要求主人和pet表演Meera故事，Marco将作为“罕见失联Child”首次向全月公开。Amicus在Trial前三日才真正开始教舞，准备时间极短。

这一阶段，Marco得知Drusus—Meera国家神话、Children债役、近两三百年衰退与Khemian战争，也发现宫廷自动化的政治边界：Com和无人机能开门、送餐、裁衣、清洁、警戒，却不是sapient；皇族私人房间因古老隐私规则不被持续记录，只有正式皇帝能锁门。数千年前为防皇族相互监视而设置的盲区，后来反而方便偷拍、阴谋和暴力。

Marco睡眠中多次进入无边界黑暗。观察者先询问死亡意义，再询问Amicus是否有能力做皇帝；它受指令限制，只能短暂提问，却一直跟随Marco。此时观察者尚未自报Monitor身份。

#### 6. 到宫约两周半：音乐与舞蹈Trial

Marco到宫约两周半时，全Adastra放假观看第一场Trial直播。Lupas、Ad Rotae、Lux、Gebii、Tricelli的triumvirates远程接入，Cato在王座厅代表中央。Wolf歌唱会故意让Lingua保留原始howl，Amicus没有意识到Marco听不懂歌词与舞步提示，演出很快失序；Cassius与Alexios准备充分，完成乐器、歌唱和充满激情的Meera舞剧。

六个评判单位全部投给Cassius。Marco以“Simian pet”身份暴露在全月公众前，却仍被当成低智Child，真实Human身份未被发现。第二场修辞Trial定于约两周后；若Amicus再败，帝位竞争便结束，若胜则进入pugnu决赛。

第一场Trial后，Cassius私下主张逐步废除triumvirates、由中央直接统治的消息流入地方官员圈。消息最初来自Alexios的Omorfan“Chaos”任务：其情报部门要制造一个不稳定、无法恢复对外扩张的Wolf政府，而非单纯扶植某一候选人。地方triumvirates意识到Cassius登基将威胁自身生存，第二场Trial的政治立场由此提前改变。

#### 7. 首场Trial后至第二场前的约两周：修辞准备与联盟保护协议

接下来约两周，Amicus准备以两万年Wolf史为主线提出改革：完整提升Children、承认债务已经偿清、接受Khemian联盟、恢复Sibling合作，并最终走向跨银河Parenthood。Cassius则把传统主义与真实民生困境结合，强调首都外贫民缺乏疫苗、遗传性骨病药物和公共保障。

Marco的高智表现逐渐引起Cato、Virginia、Neferu与Alexios注意。Amicus担心一旦落败，Cassius会处决Marco，便与Neferu订立条件契约：若第二场Trial失败，Marco的所有权转给Neferu；Neferu则以Khemian王子身份提供公民权、庇护和可能的返Earth运输。Khemia禁止拥有sapient pet，并有义务保护逃离Wolf暴力的任何智慧生命，故这份契约既利用Wolf财产法转移Marco，又准备在转移后否定该财产关系。

#### 8. 到宫约一个Adastra月：修辞Trial、城市骚乱与avia pox暴发

到宫约一个Adastra月时，Marco自估这相当于约三Earth周。修辞Trial中，Amicus遵守不得提及对手、限时二十分钟的规则，以Wolf两万年兴衰说明改革和首次正式Sibling联盟的必要。Cassius故意点名攻击Amicus、超时、无视Cato叫停，并插播Amicus与Neferu的偷拍视频，借同性污名和“以性换联盟”的叙事煽动公众；随后转向首都外病童、贫困和医疗不平等。

五个地方triumvirate单位全部投Amicus，Cato投Cassius。地方官员主要是在阻止Cassius废除自己，结果虽符合程序，却被公众视为精英自保。Adastra City随即爆发骚乱和抢掠，帝国其他地区也出现抗议。Amicus赢下第二场，比分变成一比一；Cassius尚未正式放弃第三场，继位仍未完成。

当日皇室前往首都行政区安抚地方代表。一个毛色斑驳、眼睛充血的幼狼向Marco献花并贴脸问候。数小时后，Marco出现关节和皮肤酸痛、发热、眩晕、水疱、呕吐、抽搐、意识混乱与恐怖幻觉。Wolf医师Felix识别为avia pox：对Wolves和其他已知primates通常十分温和，却在Human体内迅速造成不可逆神经损伤。Marco因秘密抵达绕过了完整入境检查，且没有任何Human医疗profile；更关键的是，avia pox因对既有物种过于温和，本来就不在当时的常规疫苗组内。

#### 9. 疫病第1至第3夜：医学死亡与Parent修复

Felix判断Marco已经没有脑活动，将永久昏迷。Wolf临终习惯把不可逆昏迷者安置在宁静自然环境中，等待自然死亡或极罕见的Parent奇迹；Amicus因此把他放在花园小型露天剧场，用花与薰衣草围成守灵花圈。

观察者承认没有预见Human对avia pox的反应，却坚持Marco仍在正确道路上。修复过程令Marco主观体验到从颈底沿脊柱和四肢扩散的灼烧剧痛。第三夜后，他在花园醒来，黄痂脱落后皮肤完整，脑损伤也消失。普通Wolf医学已确认其无恢复可能，这次复苏只能由Parent级力量完成。

Felix因找不到Marco所属物种profile，确认他并非Simian，并让Cato锁定非法First Contact。Cato立刻把Felix关入地牢，准备消灭秘密。

#### 10. 复苏当日：伪造第三Trial与Cato第一次政变

Marco醒来后与Amicus睡至日落。Cato以整个帝国可能再次被Romanus抛弃为理由，宣布不再遵守Trials规则；他以Marco生命胁迫Amicus当日故意输掉第三场。Trial不向公众直播，只录制Cassius胜利姿势和伤势，再编造正式理由。

Cato先重击Amicus使其流血倒地，让Cassius摆出踝锁与胜利动作。Marco抢到Nervo击倒Cassius，Amicus则撕扯Cato的visor保护Marco；宫防无人机最终击昏Amicus。Cato把Amicus送入地牢，把Marco限制在Neferu客房内。Neferu以pharaoh之子权限单方面授予Marco Khemian citizenship，使处决Marco等同攻击Khemia，迫使Cato暂时放弃即时杀害，只保留离宫即执行的命令。

#### 11. 伪Trial后三日内：Cassius低调加冕

三日内，Cassius低调加冕，Cato为他戴冠并成为advisor。官方声称Cassius手脚石膏来自第三Trial，完全隐去Cato失去visor和Marco反抗。Amicus继续被关地牢，Felix也未获释放，皇宫因此一度没有现场医师。

Cassius数次尝试联系Romanus，却没有恢复Stretch。他在冥想室燃烧南部植物somni，白烟带强烈化学气味，引发呕吐、恐慌、时间循环、空间拉伸和意识脱离。Monitor借这次通常只会致幻的仪式，把Cassius与Marco带入同一意识空间，公开称Cassius为false emperor，并第一次向Marco说明自身身份。

Monitor解释，Parents曾借Hindos与Meera约束Wolves，但效果比预期短；Marco要继续Meera的工作，阻止Wolf文明把Galaxias拖向毁灭并恢复Amicus合法帝位。Humans曾被多个Siblings放弃，却仍被所有Parents选为当前关键变量。Parents能看见未来路径，但不是全知者；直接干预越多，未来越难预测。

#### 12. 首次somni共享体验当日至三日后：Omorfan间谍网与Archive证据

共享somni体验当日，Monitor给Marco“看猫”的线索。Marco跟踪Alexios到湖中小岛，发现巨树树洞中的Omorfan植物通信器。Alexios每周在此发送一次情报，活体树枝构成天线，把信号送往Adastra City的第二名间谍，再中继至Omorfa。Neferu以向Cassius揭露叛国相威胁，要求Alexios开放完整Archive。

Alexios在三日内取得权限。Archive的蓝色发光球保存了伪Trial全景影像、Potes坠机调查和Marco的生物profile。Virginia、Neferu与Marco复制Cato重击Amicus、摆拍结果、无人机镇压等证据，也导出导航恶意软件、调查被叫停和调查员失踪的材料。Marco把自己的profile彻底删除，使Com还能听见他的声音，却不能把他精确绑定到身份、坐标与离宫处决指令。

#### 13. Archive行动后第1至第3日：逼宫失败与Cato第二次政变

Archive行动次日，Marco把Monitor任务告诉地牢中的Amicus，并与Neferu确认逼宫计划。再下一日，Cato外出Ad Rotae时，Virginia与Marco向Cassius出示三组材料：伪Trial完整影像、Cato袭击Neferu的录像、Potes坠机与灭口链。Cassius同意在翌日早餐后宣布退位、撤换Cato；若他反悔，材料将在第十四小时向全月公开。

当晚反政变阵营短暂庆祝。翌日早餐，提前返宫的Cato已控制酒杯，并要求Marco亲手把酒递给Cassius。Cassius饮下后迅速窒息、痉挛并吐出红色泡沫；Virginia立即诱导呕吐并呼叫医疗飞船，后来送达的解毒剂保住其生命。Cato把事件宣称为“Child pet毒杀皇帝”，重击试图救人的Alexios，拘禁Marco，并在约第十一小时自行称帝、解散triumvirates、宣布absolute control。七座主要城市同时暴乱，Adastra City天际线被烟柱覆盖。

#### 14. Cato称帝当日下午：处刑场、pugnu与皇位更替

Cato计划强迫Virginia与自己成婚，并在第十四小时于royal amphitheater公开处决Neferu。他把Khemian王子冠以虚假联盟提供者、jackal娼妓等称号，准备在Drusus雕像前用金色宝石匕首行刑，再向全Galaxias直播Wolf退出外部干预的主权表演。

Marco利用已删除profile造成的定位盲区跳入湖中，潜回地牢。Cassius先前授予Alexios极高安保权限，Alexios因此能把Amicus从prisoner list移除。距第十四小时只剩十四分三十一秒时，Marco与Amicus赶到露天剧场。Amicus以皇族birthright向Cato提出争夺皇位的生死combat trial；Cato在全国直播和荣誉压力下接受。

战斗不用武器，以牙、爪、打击和关节技至一方死亡。Cato虽失明，仍凭听觉、经验和力量击碎Amicus鼻部并锁坏肩关节。Marco违背无武器规则，用处刑匕首从背后刺入Cato肋背和颈部；Cato反击割开Marco咽喉。Amicus随后撕开Cato喉部，Com在Cato死亡后立即宣布Amicus胜利并称其为Emperor。对岸首都传来欢呼，制度判定以挑战者存活、在位者死亡为核心，没有因第三方介入撤销结果。

#### 15. 同日傍晚：Marco死亡后的第一处分岔

Marco失血死亡，意识进入Greater Intelligence／Amalgamation：无数心智既保留个体痕迹，又趋向融合，自我边界开始溶解。此处形成第一处分岔。

在终止路径中，Parents承认这一结果并非原定理想，却判定Marco已经推进Meera的工作；余下任务将由后来的智慧生命接替。Marco随即彻底融入Amalgamation，其独立意识不再返回物质世界。在续行路径中，Parents表示这次死亡仍会被阻止，并让Marco等待Amicus。Amicus把遗体抱到Archive并接入蓝色球体，使活人意识追上刚进入融合体的Marco；Marco被重新抽离并获得身体，Amicus的战伤也在意识空间中消失。九个月准备期、月球巡访、Earth任务及Khemia时期都建立在这条续行路径上。

Monitor为Parents打开通道。Parents借Marco的Lingua和身体发声，揭示Earth是成功的多Sibling文化微观实验；Amicus的任务是联合Siblings，第一步修复Khemia关系；Marco的任务则是启动Human融入。它们也揭示The Other正在宇宙边缘扩张，Galaxias需要为许多千年后的相遇准备。

Marco颈伤仍致命。Parents向Amicus提出真实条件：若他完全服从其“善意意志”，就重建Marco；若拒绝，Marco自然留在融合体，它们等待未来皇帝接替。Amicus在爱人生命压力下提交。外部物理时间近乎停滞，Marco的气管与声带被替换为Parent机械结构，颈部只留细线状痕迹，声音短期略高并带机器感。

#### 16. 决战后第1至第3日：新政府成形

Amicus立刻投入加冕、会议与七城善后。公众迅速把combat trial改编成戏剧，用戴Human面具的小Wolf扮演Marco，把他塑造成因忠于主人而破坏规则的noble savage；社会喜爱仍没有摆脱物种等级观。

决战第二日，Amicus向Marco说明Parent条件和八年Earth任务。Marco可拒绝，却会失去Parent返Earth运输，Earth整合延迟，Amicus也被禁止去Earth见他；他也可永久留在Adastra。任务开始前约有九个Adastra月准备期。Human不会被任何Sibling征服，而以Sibling-like地位进入Galaxias。

Cassius因及时催吐和解毒剂恢复，正式放弃帝位，并准备担任Chief of Social Affairs，把工作重心转向Triumvir Cities以外的贫民、医疗和资源。Virginia成为chief advisor，成为狼族史上极少见的女性最高行政人物。Alexios先被放逐到首都市中心高安保住所并切断Omorfa通信，后来由Cassius担保，获准在严密监视下随其巡视贫困地区。新政权没有把所有旧参与者处死，而把其能力分别纳入社会改革、外交和安全控制。

#### 17. 决战后数月：改革、Khemian断交与重新谈判

Cato曾在处决Neferu前主动公开自己袭击Khemian王子的影像，画面传遍Galaxias。Khemia因王族受辱和险遭处刑切断全部Adastra外交关系，迫使Amicus从低于原点的位置重启联盟。Khemian条件包括Wolf皇族为历次战争和Children伤亡道歉、承认对等外交、处理pet与债役制度。Potes时代只承认攻击Khemian武器基地、不承认杀害Children的说法已经无法支撑谈判。

Amicus开始推动女性可自行向法院申请离婚、Children完整提升、债役终结和地方资源再分配。Virginia处理北部小provinces财政，证明七座主要城市之外还有缺乏代表权的行政地区。她进入chief advisor职位之初遭遇“以性换取效率”等谣言，数月后公众才逐渐习惯女性掌握最高行政权。Cassius在贫困地区巡视，Alexios随行并受额外护卫监视；改革政府一面利用两人的地方影响力，一面阻断Omorfa继续通过他们传递指令。

Marco开始服用为primates配制的寿命延长药物。因成年后才开始，Felix预计最多增加约一百年，而Wolves通常可增加约二百年；Marco按常规治疗可活约一百五十至二百年。他也学习Wolf的Language。该语言结构与Earth Latin高度相似，Marco凭Latin和Italian基础在数月内掌握有限口语与书写，从Lingua的“配音感”后面听见真实Wolf语言。

Khemia任命Brunis为常驻大使，并让vizier与他同行，以短期代表团开启正式谈判。代表团选择Varro大学而不是皇宫，因为大学保留Khemian研究者，是帝国少数对Khemia相对友好的机构。Vizier只停留约一周，Stretch航程又使其比Wolf方预期更早抵达，Amicus不得不在Lover’s Day放下私人安排立刻开会。Brunis作为Deshereth两名幸存狼獾之一坐进谈判团，使战争道歉不再是抽象外交条款。

这一时期，Marco在Varro大学经历星球死亡、恒星枯萎、黑色触须与雕像扭曲等异象。Neferu解释Khemian关于宇宙周期残余的传说，Amicus则提醒那场真正扩张仍在数千年以后；两人无法判断大学“闹鬼”究竟是残余、心理投影还是普通噩梦。后来Monitor只明确确认另一场呈Meera形貌的拟态入侵来自The Other；大学异象与其高度相似，却始终没有得到同等的逐案确认。

Amicus同时把Human文化作为改革参照。他利用Com在Earth短暂停留时保存的Nexus片段，筹备以Italy食谱为起点的人类餐厅，尝试复制Neapolitan pizza；又研究Earth浪漫婚姻、同性婚姻和跨物种伴侣制度。Wolf法律当时既不承认同性婚姻，也不承认跨物种婚姻，他计划先建立法律基础，再让Marco以Emperor Consort身份结婚。湖岛求婚采用下跪和戒指，属于有意移植的Human仪式，而非Wolf原生传统。

#### 18. 出发前数月：九个月准备期进入后段

距离Earth任务开始只剩数月时，Amicus安排Marco巡访月球主要城市，使未来的Human联络者在离开前理解Adastra内部差异，也让公众把Marco从“忠诚pet”重新认识为具有政治角色的伴侣。行程预计持续数周，先往Lux，再去Lupas，最后前往Ad Rotae；Cassius会从最后一城返回。最初一周也被两人视为离别前可以相处的短暂假期。

这次巡访没有脱离Parent工程。Monitor在启程前收到第二项观察指令，虽然认为Marco与Amicus已经承受过多，仍开始监控。Parents没有公布指令终点，只让地方危机、Alexios处置和Marco的自由选择在同一路线中相互推动。

### 六、离地前月球巡访编年

#### 1. 启程日清晨：历史对照与湖岛通信器

巡访启程日，Adastra已进入较暖月份，气候接近Marco最初到达时。Marco留在月球已有数月，Earth离别日正在逼近；他两个月前曾严重晒伤，约一个月前在Varro大学短暂见过Brunis。自大学异象发生后，他也已连续数月感觉某种存在正在观察自己。

清晨，Marco听取《Adastra: A History》中的一万年皇统，并调出Khemian反论逐章对照。他第一次把Quarto-2413b官方“清除违法提升”与Deshereth屠杀完整拼合，确认Potes派Cato突袭、五百余Khemians和十三万五千狼獾死亡、只有两名狼獾获救。成为Emperor伴侣意味着他必须面对Wolf国家的历史责任，而不能把罪行推给已经死亡的统治者。

随后Marco与Neferu游往湖心岛，发现Cassius和Alexios重建Omorfan植物通信设备。Alexios在间谍身份暴露、母星失联后仍试图恢复联系；Cassius则因感情和对Omorfa局势的兴趣参与。岛在通常信号拦截范围之外，藤蔓、电子叶材和巨树天线能规避Wolf常规通信监控。

#### 2. 启程日下午：大学简报与Alexios处置争议

一行人乘自动马车前往大学。Amicus必须在多项风险间决定Alexios命运：Wolf传统会迅速处决严重叛徒；直接杀死一名Omorfan前外交人员会给Omorfa战争理由；驱逐会让其恢复母星联系；Cassius又以自身政治支持为担保反对处死。Virginia主张把死亡伪装成意外，Neferu与Marco坚持采用Khemian式克制，不以秘密暗杀解决外交难题。

Marco试图指出“制造事故”与Potes坠机的相似性时，Parent机械声带突然卡死。他强行发声后短暂挣脱控制，并决意亲自警告Alexios。走向Alexios的途中，物理时间停滞，Marco被Monitor拉入非物质层面。Monitor要求他继续数千年工程；Marco则以拒绝任务相威胁，换取Parents承诺Alexios不会被处死。返回后他已被挪到稍后的时点，没有真正完成警告，因而怀疑这场反抗和谈判本身也在Parents预见之内。

熊族向导Bjarni公布三城任务。Lux是北方资源命脉，需要修复皇帝合法性；Cassius以当地人气协助。Lupas是文化中心，也是分离主义、Wolven至上邪教和刺杀风险集中的城市，Marco要发表Human演讲，Neferu则公开代表联盟。Ad Rotae作为娱乐之都，用于完成政治工作后的亲民休整。主要目标需要数周，不是单一七日旅程。

代表团由Amicus、Marco、Virginia、Neferu、Cassius、Alexios、Bjarni和Brunis组成。Amicus是皇帝，Marco是Human与未来Galaxias接触象征，Virginia代表中央行政，Neferu是非正式Khemian大使，Cassius连接地方反对派，Alexios被包装成“被制服的破坏者”，Brunis是正式Khemian大使与Deshereth幸存者。地方成员会在各城依政治结果加入。

#### 3. 启程日稍晚：一小时飞行与抵达Lux

从大学返回现实后，代表团登上飞行器，约一小时抵达Lux。远北山地由灰冷城市、锯齿状雪山、滚动丘陵、巨石和褐色耐寒植被构成，与湿热的首都完全不同。城内宵禁严格，街道空荡，居民从窗后窥视；公开鞭刑仍存在。Wolf中央无人为Human准备保暖设备，Marco、Neferu被临时交给Brunis，使用Khemian便携气候无人机穿城。

Brunis确认自己就是Deshereth仅有的两名狼獾幸存者之一。他的伤疤、义肢、Khemian教育和大使身份把屠杀、uplift成功与当代联盟集中在同一人物身上。Lux曾长期承担全月最大自然资源产出，却因山地隔绝、腐败triumvirates、慢速交通和资源外运而贫困；当地矿物必须先以步行或马车运出山口，再经河船送往Tricelli精炼分配。

#### 4. Lux第1日：pugnu表演赛与代表权

Lux的地方代表Magis要求以pugnu表演赛确认自己能否加入巡访。Amicus原本准备故意落败，避免剥夺地方席位并引发暴乱；Magis的实力远高于预期，先踢中腹部使Amicus失去呼吸，再击中口鼻令其昏迷，真正赢下比赛。

结果满足Lux对尊严和代表权的要求，Magis加入代表团。Amicus的羞辱主要来自全国直播中被地方人物迅速击倒，以及Wolf社会把男性身体优势与皇权形象绑定；政治目标本身反而达成。代表团入住城外约一英里的皇家别墅。别墅以抛光木材、金边家具和大量华饰构成，远比首都皇宫奢华，邻近天然硫磺温泉。

#### 5. Lux第2日清晨：骚扰、温泉与交通议题

第二日，Neferu与Brunis在城内遭反Khemian骚扰。便携无人机镇压后，事件迅速被传播成“外来者与皇帝暴力压迫Lux”的谣言，多个不满群体开始联合。Marco与Amicus暂时离城前往山中天然温泉；泉水清澈、极热、含硫并带丝滑触感，首都人工浴场正是模仿其矿物成分。

途中Marco追问普通居民如何离开Lux。自动马车约为步行速度两倍，但必须先走出山区，从Lux到Adastra City仍需约两周；道路使用数千年，却没有把资源城真正接入月球政治中心。Marco由此提出，若帝国想统一各地，就必须连接人口和物资，而不能只在危机时派皇帝演说。交通基础设施成为可能回应Lux不满的第一项具体政策。

#### 6. Lux第2日中午：联合抗议与未完成方案

中午前后，反Khemian骚扰、宵禁、贫困、地方代表权与无人机镇压汇合成联合抗议。Bjarni建议数小时内撤离，以免皇帝遭杀；Amicus拒绝让Lux比到达时更糟，主张留下处理。Cassius承认自己第一次演说的激烈措辞也加重了局势，提出解除宵禁、让公众到场并亲自重新演讲。

Cassius没有现成的财政承诺，只想先给Lux“一点对未来的希望”。Marco提出道路和交通后，他想到一个需要Amicus、Neferu与Marco共同参与的方案。此时代表团尚未前往Lupas和Ad Rotae，Lux如何平息、方案具体内容及其后多周行程都尚未公开。当日午后，宵禁与抗议即将正面相遇，皇帝拒绝提前逃离，Cassius准备以公开演说把地方尊严、Khemian联盟和Human基础设施思路合成一次政治冒险。

#### 7. 巡访后续与九个月准备期的位置

Lux第二日午后的具体化解过程、Lupas阶段的细节与各项地方协议仍无确定结论；能够确认的是，巡访后来继续并完成。Marco至少亲历Lux山地与Ad Rotae娱乐设施，沿途住进皇室villa，与Amicus散步、钓鱼和狩猎，最后在接回Cassius与Alexios后结束。到Marco离开Adastra的最后一个完整日时，这段巡访已经结束三个多月。由此，月球巡访位于九个月准备期的后半段，却不紧贴Earth出发日。

### 七、Earth任务启动与皇位危机元年终点

九个月准备期结束时，Marco正式接受Earth整合任务。Amicus驾驶帝王飞船送他返回，同行者以Khemian亲密告别礼祝愿旅途；Neferu把Marco称作brother，表示私人关系已超越最初的外交利用。

飞船进入Stretch后约十小时抵达Earth附近，退出后再用约二十分钟接近Rome。它以cloaking进入大气并停上Marco公寓屋顶，未引发公开目击。此时距离Amicus最初绑架已近一年；Marco回到约凌晨三时的Rome，物理环境看似回到起点，身份却已从学生变成Human—Galaxias整合执行者。

Parents交给他一根约一英尺长的细银棒，轻触顶端会展开蓝色全息平面，并与Lingua连接显示地图、任务和路线。第一项指令要求他在一小时二十分钟内前往European Commission offices，委员会已经等待；系统规划半小时后巷步行路线，以避免在城市中公开露面。这说明部分Human机构已被提前联系，Marco的任务不是从零证明外星生命，而是按步骤扩大既有秘密接触。

整合预计持续八年，European Commission是两条续行路径共有的第一站。在质疑路径中，Marco以退出任务相威胁，迫使Monitor提前说明更大框架：先推动欧洲、非洲、亚洲与美洲进入可协商结构，再处理华盛顿、北京和莫斯科等关键权力中心，并以平等成员方式完成Human统一；具体外交、制度与强制边界仍未说明。服从路径中的Marco在出发前并未获得这份完整次序。两条路径随后都由Amicus返回Adastra、Marco留在Earth而进入长期物理分离。

### 八、Khemia当代：Cato骚乱三年后的双星危机

#### 1. 三年间的总体变化

Khemia使团时代发生在Cato称帝、七城骚乱与royal amphitheater决战约三年后。Neferu在Adastra生活已超过三年；Adastra为修复Khemian关系投入约四年，筹备始于皇位危机前后，却始终没有完成正式联盟。远距谈判在出发前三个月停滞，Khemian高层拒绝只靠portal作最终决定，pharaoh又要求Amicus亲自前往Khemia。

Marco此时已在Earth执行八年任务约两年。Earth report已累计到第134份，说明两地保持制度化信息往来。Adastra国内也开始试行republic机制，建立Senate并给各城投票权；公开斗殴很快出现在Senate，影像被其他Sibling新闻频道传播。Lupas要求超过人口比例的票权和对帝国决定的veto，Lux仍保留反中央传统，女性摄政合法性也持续受攻击。

Omorfa对Adastra—Khemia联盟的敌意加剧。Alexios完成破坏任务后曾获赠一艘带Stretch Drive的飞船；Cassius后来前往Omorfa，却被事实软禁，并听见“只要其他方完成各自角色”之类协调暗语。Amicus离开Adastra后，Cassius偷走Alexios的飞船返回，警告Omorfa可能趁帝国内乱行动。

#### 2. 出发前两年：Scipio候选期

Wolf青年Scipio就读Varro大学，专攻Khemian历史、语言和文化。Cato骚乱期间，大学与宿舍遭暴徒袭击，他的同学约三分之一死亡或残疾；这场创伤形成反复发作的ahewawi。他的跨位面gift是另一项并存特质，现有知识并未在二者之间建立因果。

Veteris在两年前从学生中选出三名候选人，训练其担任Khemia使团助理。Scipio与另外两人持续竞争，直到出发前一周才由Amicus与Veteris最终选中。在此以前，他只被允许知道完成工作所需的最低信息；Earth与Human的存在也直到出发前一周获选后才向他开放。

使团的公开职责是外交、文化记录和教学合作；秘密职责则是让Scipio通过Neferu、Brunis与Khemian机构逐步建立情报网络，记录Khemia远超Adastra的技术。Wolf方面既真诚需要联盟，也害怕在信息和技术上完全受制于对方。

#### 3. 出发前第1日白天：Earth疫情与使团改组

使团启程前一天，Com送达Earth report 134。Marco出现间歇性avia pox排毒：三名美国外交人员先后死亡，其中一人曾去过餐饮场所并感染四名英国官员；四人都在两日内死亡。除 Marco 曾获 Parent 直接重构这一特殊情况外，已知Human病例发病极快且全部死亡。Marco被隔离，美国与英国暂停谈判，并威胁再有死亡便退出；当时没有继续扩散的确认病例。

同一种病毒对Wolves和其他已知primates通常不构成严重问题，Marco在皇位危机元年却曾因此医学死亡，如今又能在无症状或间歇状态下排毒。Parents安排的Earth桥梁因而在Human政治视角中近似生物武器。Amicus一度考虑把Marco接回Adastra，却无法在联盟任务和Earth危机之间同时亲自行动。

大学会议当日上午，Amicus宣布自己接受Khemian要求，将亲自加入使团；Virginia留守Adastra，成为Empress Regent。同行核心包括Amicus、Veteris、Scipio、Neferu与Brunis。Amicus预计驻Khemia至少数月，若进展顺利可超过一年；Virginia与Cassius按整整一年准备帝国权力安排。

#### 4. 出发前第1日夜：Clay District暗杀

当晚，Scipio与Neferu前往Adastra City最贫困的Clay District。该区反精英情绪强，分离主义者活跃；Neferu在失去皇宫身份后曾在Clay与Silk District短租住处。一个持刀男性Wolf潜入两人所在den实施暗杀，暗中跟随Neferu的皇室无人机使目标呈波形弯折、扭曲并爆裂，瞬间完成致命neutralization；这种效应的物理机制没有名称。

Com初步判断袭击可能与近期激进化的分离主义者有关，但没有完成组织归属。若Neferu在贫困城区被杀，Khemia会把三年多的保护失败视为敌对行动，联盟可能倒退数代甚至引发战争。暗杀同时证明Adastra内部有人希望用Khemian王子之死推动帝国分裂。

Scipio在惊恐中听见干枯树叶般的意识，内容不断把Clay居民、低教育者和生命本身贬成应被毁灭的对象。它利用其创伤和阶级厌恶，把外来意志伪装成内心思想；声音与诱导方式同后来被称为The Leaves的表现一致，但此刻尚未获得独立身份确认。

#### 5. 次日上午：Khemian飞船抵达

Khemian国有飞船在次日上午降落Adastra。它不是Parent赠物，而是Khemians自行设计建造，外观与Parent飞船同样平稳，性能甚至更快、更舒适。起飞后数秒便从皇宫湖景上升到可见整颗月球的高度，随后进入Stretch。

航程约十二小时。飞船内的Ahm可通过Lingua驻留个人意识界面，受Khemian国家权力层级控制；Scipio第一次切身体验到Adastra只能使用、Khemia却能制造和改进的技术差距。Brunis携带papywei，即Khemia培育的Omorfa原生chronoma品系，用于缓解运动病、疼痛和精神困扰；Scipio闻到附近烟气，但Brunis否认向他吹烟，足以产生药效的暴露没有得到确认。

Stretch使planes之间的边界变薄。Scipio在冥想中进入中间层，先后遭遇枯叶声、自称Meera且反对Parents与Amalgamation的Hindo女性形象，以及一个清晰的年轻jackal女性声音。只有最后一道声音的身份得到确认：她来自仍活着的Aya，保护Scipio，并让他向Neferu说出Khemian句子“nettek aum hotep akh”。枯叶声与Meera形象究竟是两个独立意识、同一意识的不同投影，还是另有关系，仍未确定。

#### 6. 抵达Khemia：沙色行星与王室接待

飞船退出Stretch后，Khemia呈现为覆盖尘埃大气的巨大米黄色行星，表面积约为Adastra的十二倍。极区融水带是古文明起点，赤道依旧炎热缺水，却被Sahira’s Tower和遍布全球的改造结构纳入行星系统。地表可从轨道看见非自然线条与文明图案，云层和大气流动围绕恒星能量工程组织。

使团在克门王宫降落后被迫在烈日下等待，再接受过度礼貌的正式仪式；Scipio怀疑这是一种有意施压，但没有得到确认。王宫以直线、角形、鲜艳绘画和成带凹刻hieroglyphs为主，保存数千年风化和褪色痕迹；纳米材料主动抵消声音，使内部安静到近乎压迫。克米亚建筑哲学认为古老建筑拥有babekhen，会因长期生活、事件和历史形成“建筑之魂”。

Pharaoh没有出现。Ramoses宣称父亲正在Omorfa访问，但pharaoh至少一年未在Khemia公开露面，约两年没有可信公开消息，Neferu本人三年未见父亲，Cassius在Omorfa也没有听说其到访。Ramoses以vizier身份实际主持国家和谈判，并不断把pharaoh归期推迟数日。

#### 7. Khemia落地第1日：谈判停滞与Aya相认

Ramoses在此前协商之外临时增加旧怨议题，反复强调Wolf暴力、承诺和礼仪，却不提供可签署方案。Khemian外交文化把暴力爆发视为失控和软弱，一项承诺即使因时代变化无法兑现，也足以摧毁一代互信；Ramoses正利用这种文化优势迫使Amicus在每个旧案上表态。

Aya与Neferu重逢，并确认自己就是Stretch途中保护Scipio的声音。她是Ahhotep统一以来第八十三任sakhaet，约从十五岁开始训练，已任职约五年。Sakhaet不以语言同Parents对话，而是感知其动机、情绪和引导；Khemia、Hindo、Omorfa与Taharka都保存相近传统，Taharka称对应职位为dakhur，当前dakhur是lion Zanmek。Wolves没有现存正式对应职位，古代somni仪式只留下残缺影子。

同一时期，留守Adastra的Virginia发现原先答应协助的egalitarian senators在一天后集体失联，约十名应在场的advisor也不见踪影。Lupas否认她的摄政头衔并要求男性共治，财富来源又出现异常。Cassius从Omorfa返国后先担任她的magistros／chief advisor，准备进一步成为co-ruler，以男性身份稳定Lupas和旧政治关系；两人同时防范投毒、政变与Omorfan外袭。

#### 8. Khemia落地第1夜：秘密接触室与Gift开启

Aya把Scipio带入王宫秘密contact room。入口由古老hieroglyphs环绕，Ahm按个人授权控制；室内墙线像退入远方，空气带压力，地面细软近似面粉或流沙。核心设备veil thinner人为复现Stretch令planes边界变薄的效果。

Aya解释，少数sapients拥有能跨planes移动的灵活心智。使用者先寻找自己的key，打开和关闭意识gate：Scipio的key是meditation，Aya的是palm-reading，Zanmek使用石块和crystals。Gift不是随意读心；稳定远距联系通常只发生在同样gifted、亲自认识并建立bond的人之间。Scipio能感觉远在Lux的母亲和近处Neferu，却无法穿透普通心智屏障。

初次训练中，The Leaves伪装Aya、制造灼烧般痛苦并以Scipio最深欲望诱导他服从。真正的Aya把他拉回肉身。她说明过去十年里，四个保留gift传统的Siblings都出现过The Leaves；它对每个人采取不同形貌，却必须取得受害者真正的want，单纯恐吓或强迫不足以使人彻底fallen。现有记录只确认没有已知sakhaet向它屈服。

#### 9. Khemia落地第2日上午：Parent合并与概率视角

次日上午，Ramoses以Scipio只是学生、地位不足为由，把他挡在正式谈判门外。Scipio在失落中发现Adastra发行的Khemian反论删去了完整wolverine章节“The Price of Metal”，再次意识到本国对Deshereth历史的系统性删除。

Aya继续训练。Scipio通过veil thinner向上进入Parent plane；The Leaves在该层没有力量。随后他的意识不只是感知Parents，而是短暂与其视角合并。现实被拆成向所有方向延伸的无限threads与possibilities，时间不再只向前流动，而成为可从侧面整体观察的结构。Parents以编号追踪sapients，计算timeline corruption、nullification代价和Galaxias整体风险。

一名编号2,455,785,455,673的sapient，其加速时间线腐化风险从42.751%升至73.221%。Parents考虑nullify，因该行动会令Galaxias完全corruption风险达到百分之百而否决，转为持续观察。编号身份没有向Scipio显明，不能确定就是他本人。

另一名编号2,456,133,267,109的Human／Earth个体，其成功unification概率从22.581%降至12.554%；在“arrival”以前完成full unification的概率仅0.00000011%。对应pathway由delta1082-B7M8-Beta降为delta1082-B7M8-Zeta，观察级别改为minimal。Human极可能与Marco相关，但“unification”究竟只指Earth统一还是更大的Galaxias整合，“arrival”究竟是否指The Other，均没有被Parents命名。

返回肉身后，Scipio从左眉上方到颈根剧痛，Lingua附近抽搐。Aya判断他看见了Parents内部处理现实的方式，这种经历在历代sakhaet中也极少发生。她同时承认，自己近来常完全感知不到Parents；偶尔得到的信号也克制、冷淡，像是主动降低参与。

#### 10. Khemia落地第2日下午：Ramoses越权与联盟最后期限

Ramoses很快准确知道Scipio透过Parents所见的秘密，把他单独带到王宫外沙地，指控Wolves利用Aya从事间谍活动，并以espionage罪威胁拘押。他还要求Aya预言未来、跨星球侦察其他Siblings，声称有人从远方监视自己。

使团成员拥有diplomatic immunity，Khemian公民又有批评pharaoh和私人空间不受监听的权利；Ramoses无权因王室成员自愿传授秘密而囚禁Scipio。Ahm能够覆盖使团的privacy directive，contact room内容又迅速泄露，说明vizier最高权限已经把政策层隐私变成可随时撤销的承诺。Neferu由此认定兄长正在主动破坏使团。

Amicus宣布：如果真正pharaoh在三日内仍不出现，他将中止任务、放弃联盟并离开Khemia。Ramoses继续把会面推迟“几日”，却没有给出可核实归期。Aya、Scipio、Amicus、Veteris与Neferu都意识到王宫被监控或权力失控，但各自只掌握部分情况。

#### 11. Khemia落地第2夜：Neferu旧罪与当代悬局

当夜，Neferu坦白自己少年时加入Children of Sahira的经历。他十六至十七岁接触反Adastran思想，十八岁已进入组织高层，并利用王室位置盗取资金；虽然没有亲手伤人，他认定自己的钱间接导致数十人死亡。组织被捕后，pharaoh掩盖其涉案，将他在王宫dungeon封禁数月，累计接近一年。

Aya说服父亲不用终身监禁或死亡，改为五年密集学习Adastran语言与历史，再让Neferu成为战争后一百多年里第一名踏上Adastra的Khemian，以促成联盟赎罪。Neferu留在Adastra三年多、承受Cato处刑威胁和国内分离主义暗杀，都是这一惩罚与政治任务的延续。

使团抵达前一日，Children of Sahira已卷入一宗被列为机密的Khemian事件；约二十万本地Omorfans中也突然出现大规模反联盟抗议，尽管几个月前多数仍支持和平。次日使团计划进入Khemen，由Amicus向公众讲话；公开人群会同时暴露在Omorfan激进者、Children of Sahira、Ramoses安保和潜在外部协调者面前。

Neferu睡去后，Scipio在没有veil thinner、也没有Stretch辅助的情况下独自冥想，呼唤Meera，追问自己与Parents合并时究竟看见了什么。此刻pharaoh仍失踪，Amicus的三日最后期限仍在倒数，Virginia的摄政政府面临政变和外袭阴影，与Human／Earth有关的统一路径概率正在下降；编号个体极可能关联Marco，但身份并未显明。The Leaves也仍能在Parent平面以下等待。这一夜结束时，Meera尚未回答。

### 九、未来预见：与既成历史严格分离

#### 1. 完全服从Parent指令时的条件性未来

Monitor曾让Marco在约半小时外界时间内体验一条横跨数百年的未来。该未来只有在他与Amicus遵循全部Parent指令时才被保证，不是已经发生的事实。

这条路径中，Marco完成八年Earth任务后回到Adastra，与Amicus重聚；两人随后遍游Galaxias，接触大量未知物种和文明，Neferu成为最亲密的政治盟友。约四十年后，跨文明工作的主要阶段完成，两人返回Adastra。Amicus继续把权力从imperial family移向更广泛的制度，在一百年内让皇族正式放弃对整个月球的统治。

两人相识约二百年后退居乡间villa，再共同生活约五十年。Marco接近三百岁时在Amicus怀中死亡；数十年后Amicus也进入Greater Intelligence，两者在融合体中重新相聚。这个未来既展示Parent的跨时感知，也构成促使Marco服从的情感保证。Felix按常规药物估计Marco只能活一百五十至二百年，故近三百岁寿命还需要未来医学、个体变化或Parent干预才能实现。

#### 2. Marco意识选择的两条路径

Marco在接受Earth任务前可以沿两种互斥的意识路径抵达同一外部结果。一种直接接受Monitor展示的条件性未来，把八年分离视为数百年共同生活前的短暂代价。另一种拒绝用美好预见换取服从，追随一个呈现Meera形貌的女性意识；该存在随后语音干裂、形态异变，被Monitor识别为The Other。

第二条路径中，Marco以退出任务相威胁，迫使Monitor提前说明Earth政治步骤，并取得在每项具体任务开始前质疑、拒绝或要求替代方案的权利。Monitor承认，过早透露知识会改变当事人的决定，使Parents看到的未来变模糊；但彻底失去执行者比未来模糊更不利。两种路径最后都以Marco接受Earth任务、获得银色终端并前往European Commission结束，外部编年由此重新汇合。

#### 3. Khemia时期的概率未来

三年后的Parent视角不再给出安抚性的完整人生，而给出不断恶化的概率。Human／Earth统一成功率从22.581%降至12.554%，在某个“arrival”以前完成full unification的概率只剩0.00000011%，pathway被从Beta降为Zeta，观察级别改为minimal。这组数字不能单独证明皇位危机元年的条件性未来已经失败：编号个体虽极可能关联Marco，但其姓名、unification范围与arrival对象均未显明。能够确定的只有，某条Human／Earth相关路径在Parents当前模型中的成功评估正显著下调；avia pox造成的外交死亡、退出威胁与Galaxias多线内乱均可能继续改变后续概率。

另一个sapient的时间线腐化风险升至73.221%，Parents甚至讨论nullification，却因那会把Galaxias完全腐化概率推至百分之百而放弃。Parents既能跨时观察，也必须在相互依赖的变量中权衡；删除一个危险个体并不必然改善整体未来。

#### 4. 尚未发生的终局

Parents所预警的The Other宇宙级危机仍在许多千年以后；Khemia概率画面所称的arrival是否就是这一事件，尚未确定。Earth八年任务尚未完成，Amicus仍是皇帝，皇族也尚未放弃月球统治。Marco近三百岁的死亡、四十年Galaxias工作、一百年帝制退出和二百年后乡间退休，都只属于有条件的远景。Khemia使团的下一次Khemen公开演说、Pharaoh下落、Ramoses真实目的、Omorfa行动、Lupas资金来源与The Leaves身份，也都尚未得到最终结果。

当前有三个倒计时同时推进：Earth正在处理avia pox造成的外交崩塌；Adastra由Virginia与Cassius维持摄政和防御；Khemia王宫内，Amicus等待失踪Pharaoh，Scipio等待Meera回答。Parents已经把三条线纳入同一概率结构，却不再保证它们会自然回到最理想的未来。

## 十一、专有名词、世界常数与五感速查

### 一、宇宙秩序与生命层级术语

#### 1. Galaxias

银河内由Parents、Siblings、Children及其共同制度构成的跨文明秩序。它既是文明共同体，也是关于接触、提升、技术授权和外交责任的一整套规则。Galaxias并非单一国家：各Sibling保留本国政体、军队、文化和利益，彼此之间甚至长期交战。共同秩序能够约束首次接触和文明等级，却不能保证成员和平、平等或信息透明。

#### 2. Sapient

具有自我意识、复杂语言、长期规划、道德选择和文明潜力的智慧生命。该词描述心智地位，不等同于特定身体形态，也不等同于已加入Galaxias。天然物种、经提升的物种、人类与各Sibling个体都可属于sapient；Com和Ahm虽能自然应答，却尚未被确认拥有这种心智地位。

#### 3. Parents

来自本银河之外、能够跨越银河并在高层位面观察时间的上位存在。它们进入银河后选择若干本土智慧物种作为Siblings，提供Stretch、Lingua、Archive等技术，并以统一银河、最终实现跨银河航行为长期目标。Parents的心智可同时接触许多时间位置，能看见大量可能路径并计算风险，却不是无条件全知，也不能保证每次预测或干预成功。它们通常维护智慧生命的agency，但在认为总体未来受威胁时会打断航行、操控身体、封锁言语、制造预示或迫使关键人物选择。

“Parents”可以指整个上位群体，也可以指其中一支与某个Sibling相连的Parent谱系。银河内仍有八个Parent存在或谱系，但彼此很少公开交流；其内部结构与个体数量没有足够信息，普通生物政治分类也无法完整解释它们。

#### 4. Romanus

与阿达斯特拉狼族相连的Parent谱系。Romanus选择并提升狼族，向皇帝提供技术、授权和有限通信，也在狼族拒绝Parent秩序后撤去支持。Romanus与Galenians在进入本银河前便出自同一银河，具有极深关系。狼族将Romanus高度宗教化，但皇帝掌握的机密远多于普通信众。

#### 5. Galenians

与奥莫法猫族相连的Parent谱系。Galenians与Romanus的古老纽带曾在狼族与猫族第三次战争中产生直接影响：阿达斯特拉一方的Stretch drives失效，狼族天空出现旧神征兆与停战请求；奥莫法一方是否受到同样制裁并未说明。Galenians不可与狼族誓词中的Galen自动视作同一概念；两者关系没有明确定义。

#### 6. Kemetarians

与克米亚相连的Parent谱系。部分克米扬学者把Kemetarians视为Parents中的事实领导者，但这只是文明内部的判断。Kemetarians与Kushari由同一更早的提升者体系发展而来，分别迁徙数十万年后在本银河相遇并建立联系。

#### 7. Kushari

与塔哈尔卡狮族相连的Parent谱系。Kushari和Kemetarians共享更早的文明根系；塔哈尔卡与克米亚另有紧密的长期政治联盟。塔哈尔卡被视作现存Siblings中第二先进的文明，并曾在阿达斯特拉—克米亚第二次战争中支援克米亚。

#### 8. Sibling

被Parents直接选中、提升并授予代理职责的文明层级。Siblings负责寻找具有潜力的智慧物种，将其提升为Children，并传播各自Parent的文化和制度。阿达斯特拉、克米亚、奥莫法、Hindo与塔哈尔卡都属于这一层级。Sibling有时指文明整体，有时指该文明中的个体；不能据单数用法推定一个星球只有一种生物。

Siblings长期把体系误解成竞争，试图证明自己比其他文明更接近Parents。Parents的真正方向是合作：Sibling与其Children只有联合整个银河的智慧力量，才可能达到跨银河航行的技术门槛。

#### 9. Child与Children

由Sibling发现、提升并纳入Galaxias的智慧物种或文明。Child不是幼童，也不是天然低智生命。许多Children在提升后背负“偿还提升成本”的债务，被迫长期劳动，阿达斯特拉更把这种关系发展为制度性依附。Child仍是完整智慧主体，其科学、艺术和政治能力不会因层级名称而低于Sibling个体。

#### 10. Uplift

通过技术、教育、社会工程与文化移植，使具有智慧潜力的物种达到稳定文明水平并进入Galaxias的过程。它可能持续多个世代，不只是一项生物改造。提升者会把自己的价值观、语言和制度一并带入，因此uplift既能拓展知识，也可能建立债役、文化从属与政治控制。

#### 11. Abandoned Child

被提升者放弃、失去持续指导或与Galaxias断联的Child文明。地球曾经历多次不成功的介入，却又彻底遗失对Galaxias的共同知识，属于极少见的失联状态。此词是文明分类，不是指被遗弃的儿童。

#### 12. First Contact

Galaxias法律中的首次文明接触。未经Parent授权，Sibling不得擅自向不知晓银河文明的sapient群体显露自身。即使一个文明远古时曾受过提升，只要其社会已完全遗失外星智慧与Galaxias知识，再次正式接触仍按First Contact处理。违法接触可能引来处决、灭证乃至整个Sibling再次遭Parents放弃，因此它是最高等级的文明禁令之一。

#### 13. Parent技术

由Parents提供、Siblings可以操作但通常不能解释或完整制造的技术总称，包括早期Stretch、Lingua、Archive、部分飞船、Monitor接口及高等级医疗。拥有Parent技术不等于理解其原理。克米亚已能独立制造更快的Stretch飞船和大量先进设施，却仍未破解Lingua的核心结构。

#### 14. Parental status

Sibling与其Children发展的终极文明位阶。达到该位阶的硬性标志不是普通星际旅行，而是自主实现跨银河系航行。单个物种难以完成这一目标；银河智慧文明的协作、知识共享与政治统一是更可行的路径。

#### 15. Agency

智慧主体作出真实选择、承担后果并不被上位力量直接代替决断的能力。Parents公开把agency视为核心原则，但它们会设置强迫性二选一、隐瞒关键信息、控制喉部机械结构或以条件性未来诱导行动。因而agency在Galaxias中既是伦理承诺，也是持续争议的权力边界。

#### 16. Monitor

Parents与物质层智慧生命之间的信使、观察者和跨位面桥梁。Monitor常以龙形出现，能读取面前心智、重构意识空间中的身体形象、把多人带入共享精神场域，并向Parents询问指示。它有独立语气、情绪、同情和道德不适，却不能违背核心限制，也不知道全部未来。Monitor不是Parent，不是全知神，也不负责独立制定银河战略。

#### 17. Plane与dimension

物质现实之外的存在层级。不同plane不是单纯上下叠放的物理空间；“向上”“更高”只是凡人心智对存在层级的直觉映射。Stretch运行时，各层之间的界限会变薄；具gift者、Monitor、Archive与veil thinner都能以不同方式利用这种渗透性。进入高层状态时，身体可能仍在呼吸、出汗、昏厥，意识却感到自己跨越宇宙或同时从多个方向观察。

#### 18. Archive与Archives

阿达斯特拉皇宫内的Parent级档案与通信装置。本体为巨大的蓝色悬浮发光球，表面有蜂巢纹和旋转字符，前方立着张口石龙。它通过蓝光触须接入大脑，可依意念瞬间检索、转移或删除大量档案，也曾是Romanus与皇帝正式通信的终端。Archive还能把活人意识与刚进入融合体的死者连接至同一感知空间，并在极端情况下参与意识抽离和身体重构。

#### 19. Greater Intelligence与Amalgamation

智慧生命死亡后汇入的巨大意识总体。狼族常称Greater Intelligence，克米亚语境更常称Amalgamation；两者描述高度重合：亿万心智既保留“许多个体”的痕迹，又汇聚为单一广阔智慧。刚死亡者会感到身体消失、自我边界溶解，并可能在彻底融合前被Parent级机制抽回。

它不等于Parents本身。融合后的主观幸福、痛苦、自由程度仍存在严重争议：Monitor将其描述为安宁团聚；一名自称Meera、并声称拒绝融合的意识把它视为对生命个体性的攻击；The Other则会把它扭曲成永恒痛苦以诱发恐惧。任何单一阵营的伦理解释都不能取代已知现象。

#### 20. Un-amalgamated spirit

各文明关于“死者没有进入或拒绝进入Amalgamation，并继续在地点或跨层状态中显现”的宗教与民间概念。自称Meera的跨层意识为此留下异常线索，但其身份尚未确认；现有现象不足以证明死者可以普遍自由拒绝融合、长期保留完整人格，也不足以使所有幽灵传说成为事实。

#### 21. The Other

来自已知生命共同根源之外的异质存在或过程。克米亚的主流古老解释把它置于生命、机器与病毒之间，认为其依赖sapient consciousness维持；已确认的能力则是利用宿主意识投射形貌与影响。传说认为稀薄残余会附着物体或穿过智慧生命；当代可确认的显现能借宿主的记忆、恐惧、渴望和反应制造鬼魂、怪物、熟人或宇宙毁灭景象。弱态显现通常不能直接造成物理伤害，却能扭曲判断并从情绪反应中增强自身。

The Other以极长周期扩散，传说中的间隔以数十亿年计，宇宙边缘的主体正缓慢逼近。Parents推动银河统一的深层目的之一，就是让后世文明在许多千年后具备面对它的能力。它能进入意识与Parent接口相关的层面，但幻觉、灵体与政治阴谋也可能分别源自药物、未融合意识或普通权力斗争，并非全由它引起。

#### 22. The Leaves

过去十年间，在克米亚、Hindo、奥莫法和塔哈尔卡的gifted传统中反复出现的枯叶摩擦般声音。它为不同对象制造不同形态，抓住对方最深的愿望，诱导其真正想要并自愿服从。单纯恐吓或强制不足以让它完成控制；保有拒绝能力是核心防线。The Leaves无法进入Parent plane，却能在较低层面、梦境、雕像、冥想和肉身交界处等待。

The Leaves与The Other在声音、个性化投射、借欲望和恐惧操纵等方面高度相似，但两者尚未由掌握全貌的权威正式合并为同一名称。二者关联显著，分类关系仍未完成。

#### 23. 生命共同根源（Original source）

“宇宙这一侧”已知普通生命的共同根源。不同星球的生命因此沿相近路径演化，产生外形、器官、生态位乃至行为相似的狼、猫、胡狼、狮、虎、熊、灵长类、鸟、蜘蛛和昆虫。共同根源解释趋同，不表示不同星球的物种完全相同。The Other被认为不属于这一根源。

### 二、心智、宗教与跨位面术语

#### 1. Gift

少数sapient心智在不同planes间移动的天赋。它不是普通读心，也不等于精神疾病。具gift者可在训练后感知同样具gift且建立联系的人，进入中间层或Parent plane；普通心智周围存在难以穿透的屏障。强行深入会引发剧痛、迷失、被异质意识接触或无法顺利返回身体。

#### 2. Sakhaet

克米亚负责感知Parents、维护跨层传统的秘密职位。Aya是Ahhotep统一后第八十三任sakhaet。职位通常持续终身，也可能在找到继任者后交接或出现空缺。Sakhaet并不和Parents进行清晰对话，而是感知它们的情绪、动机和引导；这种通道比Monitor更直接，却不受Parents明确答复保证。训练、身份和接触内容受严厉誓约保护。

#### 3. Dakhur

塔哈尔卡对相似职位的称呼。现任dakhur为狮族Zanmek，以石块和晶体作为key及grounding物。Hindo保留古老仪式，奥莫法人则借本土致幻植物进入相似状态；现代阿达斯特拉没有得到制度承认的对应职位。

#### 4. Key、gate与grounding

Key是开启个人跨层状态的心智入口；gate是意识进出不同plane的门槛；grounding是维持自我、记住肉身并安全返回的锚定手段。Scipio的key是冥想，Aya的是掌纹触读，Zanmek的是石头与晶体。熟练后不一定需要重复最初仪式，但key与grounding仍能降低迷失风险。

#### 5. Bond

具gift者之间建立的稳定心智联系。通常需要亲自认识、共享天赋并形成关系后，远距感知才会可靠。它并不开放全部思想，也不让一方随意侵入另一方心智。强烈情感和命运交集可能使尚未见面的个体成为例外，但这种情况稀少且机制未明。

#### 6. Contact room

克米亚王宫内受个人权限控制的秘密接触室。入口由古老象形文字环绕，室内有模糊远退的墙线、空气压力感和近似面粉或流沙却不沾毛的细软地面。它为sakhaet训练提供低干扰场所，也因王宫权力斗争而存在被非法监听的风险。

#### 7. Veil thinner

Contact room中的“薄幕器”。它人工复现Stretch令planes边界变薄的部分效果，帮助具gift者打开gate。装置不赋予普通人天赋，也不能保证接触对象友善，更不能替代grounding、筛查和训练。

#### 8. Somni

生长于阿达斯特拉大陆南部的致幻植物。燃烧后产生白烟和樟脑丸般刺鼻气味，可造成呕吐、震颤、眼红、恐惧、空间拉伸、时间循环与怪异视觉。早期狼族在Parent正式通信中断时用它寻找高位存在。大多数somni体验只是化学性幻觉；当Monitor主动接入时，多名吸入者却可进入同一共享意识空间。因此somni不是稳定通信设备，也不是纯粹无意义的幻觉。

#### 9. Ahhotep

克米亚最重要的神圣名称、统一象征或祝祷对象。它出现在正式迎宾、远行祝福、亲密告别和日常惊呼中。Ahhotep’s Unification是克米亚统一纪元的重要起点；不能仅按一个具固定形象的普通神祇理解。

#### 10. Ahewawi

克米亚语“旧痛”，指持续、复发并影响当下的心理创伤。它既不是懦弱，也不等于gift或psychosis。克米亚文化认为旧痛可以治疗、管理，并由亲友共同承接；阿达斯特拉传统更倾向要求个体沉默承受。

#### 11. Babekhen

克米亚语“建筑之魂”。Khemian建筑哲学认为，长期存在的建筑会吸纳周围事件与生命，从而形成比建造者更持久的身份。王宫保存风化石面、褪色壁画和古老空间，正体现对babekhen的尊重；修复的目标不是把一切抹成新造外观。

#### 12. Galen与Edapol

Galen出现在猫族誓词中，Edapol是狼族在温泉等情境下发出的感叹。两者均为真实口语用例；具体神格、词源与彼此关系不明，尚无事实足以为其附加完整神话体系。

### 三、航行、通信、人工智能与医疗术语

#### 1. Stretch与Stretch Drive

跨恒星快速航行技术。它缩短飞船前方空间、拉长后方空间，使外部星光弯成白色长线，并让航行区域与普通时空产生不同步感。直视弯曲星光或对plane变化敏感者容易恶心、眩晕、昏厥。Stretch还会让不同planes之间的界限变薄，故具gift者、未融合意识与异质存在更容易在航程中相遇。

传统Sibling文明依赖Parents提供核心装置或能量；克米亚已能制造速度更高的大型Stretch飞船。Stretch只能证明银河内远距航行能力，不能等同跨银河航行。航程受船型、能量、窗口和路线影响，同一目的地不必有永远固定的耗时。

#### 2. Depletion与starbound

Depletion是Parent供能或授权耗竭、Stretch航行能力随之丧失的状态。文明一旦失去这种能力，便会被困在本恒星系，成为starbound。阿达斯特拉在皇帝死亡、继承中断和Romanus撤回支持后经历过Depletion；它会立刻切断外部贸易、Child控制、外交补给和资源网络，引发长期经济衰退。

#### 3. Lingua

植入大脑语言中枢附近的微型Parent装置，本体是不足一毫米的金属球，内部含未知液体。它学习宿主脑结构，把陌生语言和单位转换为最易理解的概念；初期会出现眼眶刺痛、抽动、恶心、原声与理解结果重叠。适配后，听感近似声音与意义被直接覆盖。

Lingua不是完美字典：歌唱、无词长嚎、双关、发音过差、未录入专名和陌生文化概念都可能失效。它还可能自动换算小时、年份和距离，因此经Lingua换算的跨文明数字只保留相对尺度，不能保证每个单位都对应地球标准。克米亚能让Ahm通过Lingua对单个用户发声，也能暂时退出或禁用这一通道；这不等于系统可读取思想。

#### 4. The Language

狼族对自身语言的称呼，通常只说“语言”，没有另一个广泛使用的专名。其结构与地球拉丁语高度相近，反映Romanus文化曾进入地球。学习The Language可听见真实音色、口音和节奏，摆脱Lingua造成的覆盖感。

#### 5. Computatrum与Com

阿达斯特拉广泛部署的环境计算、飞船控制和语音助理系统。它可检索档案、连接网络、调度无人机、监测船况与健康、接受皇帝权限指令，并在宫殿、别墅、飞行器和城市设施中工作。Com擅长按输入优化，却不具备可靠伦理判断，也经常误解习语；“不主动打断”的设置甚至会令它压住关键警告。不同场所的Com是否属于一个连续意识并不明确。

#### 6. Ahm

克米亚国家资助、研发并所有的超级计算与个人助理系统。Ahm管理飞船、医疗、餐饮、导航、药物、安保和宫廷信息，可通过Lingua私下对个人说话，也可外放。它比Com更善于理解情境、停顿和用户需求，但这种表现不足以确认其拥有主观意识。

Ahm的隐私模式属于权限政策而非物理断联：系统在退出后仍能听到唤醒词，法老或维齐尔可覆盖低级用户命令。私人房间依法不应被监听，但技术上能否做到与法律上能否做，是两件不同的事。

#### 7. Nexus

跨设备的信息网络及其文明概念，地球互联网会被Com归入Nexus范畴。它能承载档案、新闻、通信与语言资料，但各文明协议并非天然兼容；阿达斯特拉设备无法在所有政治状态下直接联系奥莫法飞船。

#### 8. Portal

个人远距通信终端。常见形态为银色短杆，敲击后展开透明发光面板，可显示文字与实时影像，收起时画面缩回杆体。Portal是终端而非Nexus本身，也不是空间传送门。

#### 9. Drone

无人飞行或悬浮设备的总称。阿达斯特拉皇室无人机负责送餐、量体裁衣、清洁、照明、拍摄、警戒、击昏与致命防卫，所有权高度集中于皇族。克米亚无人机外形更平滑，能送药、搬运行李、局部调温和执行王宫安保。

战斗型无人机可使目标呈波纹弯折、扭曲并瞬间爆裂；这种致命效应的机制尚未命名。低致命模式则能击昏群众。它们反应迅速，却不会自动解决政治后果：在Lux动用无人机镇压，即使技术上成功，也可能把骚乱升级成独立战争。

#### 10. Climate drone

克米亚便携式局部气候无人机。黑色圆顶悬浮在使用者上方，投射锥形暖区，可通过Lingua调节。它能保护短毛胡狼与人类穿越Lux寒地，却不改变整座城市气候。

#### 11. Nervo

双金属探针式神经制伏器。它以接触方式扰乱神经与肌肉，不是普通电击器。低功率会令身体麻木、绷紧、意识涣散；高功率可使成年狼痉挛、流涎并昏迷一至两小时；满功率可能致命。功率滑条与目标物种体型共同决定致伤和致死风险。

#### 12. Sightseer

皇宫湖上的透明观光悬浮艇。它像开放顶的玻璃箱，地面与侧壁透明，以倾斜触控板启动，在水面上低速、几乎无接触地滑行。Sightseer是安全型Parent技术，也可作为游泳者临时扶靠点；它不是远距飞行器。

#### 13. Mechanical carriage与automated chariot

无人驾驶的自动马车，是阿达斯特拉日常地面交通的重要组成。首都贵族常把它当短程礼仪载具；普通地区则依赖它进行漫长城际旅行。其速度约为步行两倍，从Lux前往首都需先徒步离山区，再以自动chariot完成约两周陆路行程。Lux原料才会经步行或马车送至河边，再由不载普通旅客的货船运往Tricelli。

#### 14. Omorfan plant technology

奥莫法把活藤、树枝、叶材与电子系统结合的技术。巨树可成为通信天线，树洞内嵌语音响应装置，信号再经城市中继传向母星。植物材料不是装饰，而是设备结构的一部分。克米亚已获得部分相关知识；阿达斯特拉在植被密集处更难拦截这种通信。

#### 15. Sahira’s Tower

克米亚的恒星取能与行星输能系统。轨道—地表组合结构持续朝向恒星，从恒星获得能量，再以橙粉色光束送往地表，承担全行星能源供应。其精确空间构造仍属战略机密，现有信息无法把它归为纯地面塔或纯轨道站。奥莫法曾试验相近概念，因担忧恒星系稳定而停止。

#### 16. Recovery mode与cloaking

Recovery mode是飞船严重受损后的停机恢复状态，系统会在完成自检与修复后重启；外壳损伤不必然等于船毁。Cloaking是隐藏飞船的能力，可让帝王飞船进入地球大气并停靠城市屋顶而不引发公开目击。两者都是飞船功能，不代表乘员本身具隐形或自愈能力。

#### 17. Avia pox／avian pox

同一种跨物种病毒性疾病的两种常见写法。它对狼族与既有灵长类样本极为温和，因此未被纳入当时的新到访者常规疫苗组；人类却表现出异常的极端易感性。在常规医学条件下，现有七名Human病例发病迅速且全部死亡；Marco的恢复依赖Parent直接重构，不能视为普通治愈案例。Marco还可间歇性无症状排毒，因而即使本人健康也可能传播。Human专用疫苗是否已经存在并未明确。

#### 18. Lucius fever

曾在克米亚造成数十万死亡的疾病。阿达斯特拉女间谍Antonia被俘后成为无症状携带者，并在克米亚引发疫情；她是否有意传播没有定论。它与avia pox不是同一种病。

#### 19. 寿命补充剂与Parent医疗

狼族长期服用的身体补充剂可显著延寿，并按月调节身体状态。成年后才开始服用的人类收益较小，通常仍可增加约百年；Parent展示的条件性未来中，一名Human接近三百岁，但实现这一寿命的具体医学或干预机制未明。Parent级医疗能重建喉管、声带、气道，修复骨关节与面部创伤，安装机械视觉，甚至在死亡不久、意识尚可抽离时重构身体。此能力不普及，也不意味着任何死亡都可逆。

#### 20. Papywei／pap与chronoma

Chronoma是奥莫法原生精神活性植物，papywei或pap是克米亚培育的品系及其蒸吸制剂。它可减轻慢性疼痛、运动病与精神困扰，让思绪变慢、情绪意义增强并提高共情；初次效果难以预测，也存在依赖和成瘾。Ahm按症状发放小剂量，医师可提供更强镇痛方案。它不是无限供应的娱乐品，也不等同somni的Parent接触传统。

### 四、政治、法律、教育与社会术语

#### 1. Emperor、acting emperor与imperial family

阿达斯特拉帝国最高统治者为Emperor。正式皇帝拥有Parent通信、帝王飞船、Archive和宫廷系统的关键权限。帝位空缺时，首席顾问可担任acting emperor处理事务，但不会自动获得全部皇帝技术权限。Imperial family既是王室血缘集团，也是无人机、飞船、别墅与高端Parent技术的主要控制者。

#### 2. Chief advisor、magistros与Empress Regent

Chief advisor是皇帝身边最高级政务顾问，可在皇帝失能或离开时维持行政连续。Magistros在新政时期被用于近似首席顾问的职位。Empress Regent是皇帝离境期间由Virginia承担的摄政头衔；她是统治代理，不等同已取代皇帝。阿达斯特拉父权传统会以拒绝承认头衔、色情羞辱和地方抵制削弱女性权力。

#### 3. Emperor Consort

为皇帝男性或跨物种伴侣预备的正式头衔。旧有狼族法律不承认同性或跨物种婚姻，因此该位置必须随婚姻制度改革建立。它不同于传统“妻子”身份，也不意味着伴侣自动拥有皇帝全部权限。

#### 4. Pharaoh与vizier

克米亚最高统治者为pharaoh。Vizier位于法老之下，掌握行政、外交和宫廷最高级权限，并常被视作继承人。Vizier可覆盖Ahm的低级隐私命令，却仍受克米亚法律约束；高权限不等于合法监听或任意拘禁外交人员。

#### 5. Triumvir、triumvirate与Triumvir Cities

Triumvir是地方三人执政官，triumvirate是三人执政团。阿达斯特拉主要外城由当地民选三人团治理，并参与帝位Trial评判、财政谈判和城市代表权。Triumvir Cities指拥有这套主要代表结构的城市；它们之外仍有小省份、乡村与缺乏充分政治资源的人口。三人制不保证廉洁：Lux长期受极端、腐败官员控制，Lupas则被少数富裕家族把持。

#### 6. Senate与republic改革

Amicus时期建立的共和国式试验，包括Senate和城市投票权。它与皇帝制度并存，仍处于不稳定过渡期。参议员公开斗殴、地方要求额外否决权、女性摄政遭拒，说明制度名称并未立刻改变狼族的暴力政治、寡头网络和父权习惯。

#### 7. Trials

Potes死后的继承危机采用了公开三项试炼：音乐与舞蹈、修辞、战斗，按先得两胜处理。五个地方triumvirate单位与Cato代表的中央单位参与投票，使传统才艺、公众形象和地方政治同时介入继承。该格式没有被确认是历代通常宪制；Trial也不等于普通民主选举，胜负仍可能被顾问、媒体、无人机和宫廷阴谋操控。

具有王族birthright者还可向现任皇帝提出生死combat trial。此时荣誉、全国直播和皇权合法性迫使在位者回应，最终判定更看重挑战者存活与现任者死亡，不会像现代体育一样严格复核每项违规。

#### 8. Pugnu

狼族古老综合格斗。日常比赛包含拳击、踢击、抱摔和地面控制，通常禁止爪、牙、挖眼与腹股沟攻击；表演赛可打至昏迷。生死combat trial则允许牙爪和致命咬喉，目标是死亡而非认输。日常pugnu并非死斗，且从来不只是用拳的拳击。

#### 9. Pet

阿达斯特拉把外族智慧个体纳入贵族家庭的从属制度。Pet既是私人伴随者、生活侍从和政治展示，也可在Trial中证明主人具备“教化”外族的能力。Pet要在早餐时跪地服侍、等待主人剩食，并受契约、转让与主人权限约束。它不是普通动物饲养关系，而是对sapient施行的身份压低和占有制度。新政已把Children平等、债役终结与跨物种婚姻带入改革议程，但pet所有权并未在当代被确认已经彻底废除。

#### 10. Indentured servants

以“偿还uplift成本”为名建立的长期强制劳役。部分Children从第一代提升开始便一直未能还清债务，使所谓服务事实上跨越世代并具有奴役性质。它不等于有期限、可自由离职的普通雇佣。

#### 11. Child settlement

Children居住或拥有相对独立权力的定居点。阿达斯特拉王室把它视作遭政变、Sibling攻击或本土失守后的最后避难选项，说明部分settlement可能不受狼族中央直接控制。其具体人口、地点和政体尚未公开。

#### 12. Children of Sahira

克米亚反Galaxias激进组织，名称来自推动技术独立的历史人物Sahira。现代组织使用恐怖手段攻击本国人，不能与泛称Children混淆。Sahira让克米亚摆脱Parent技术依赖的历史功绩，也不能用来替现代组织的暴力背书。

#### 13. Ad Astra policy

狼族在重新联系Parents后形成的对外扩张与Parent导向政策传统。其长期结果包括争夺Children、依赖Stretch、压制被提升文明和与其他Siblings频繁战争。该名称与月球Adastra相关，却不是星球、城市或单一法令的同义词。

#### 14. Separatist movement与狼族至上邪教

分离主义运动反对快速改革、Parent干预、克米亚联盟和外族进入，部分成员愿以死亡换取阿达斯特拉分裂。狼族至上邪教则崇拜旧狼神、宣扬种族优越并实施炸弹活动。两者成员与理念只有部分重叠，反中央抗议者并不天然属于邪教。

#### 15. Khemaphiles

对克米亚文化、历史和政治持研究或友好态度的阿达斯特拉学者。Varro被称作帝国最后的Khemaphile堡垒之一。该称呼带有国内政治色彩：研究克米亚史可能触犯法令，阅读反论甚至要求读者写文章谴责其为谎言。

#### 16. Sabayet

被誉为Galaxias最优秀的克米亚大学。录取以merit为原则，王室没有自动席位，富裕家庭的优势主要来自更充分的备考。它培养外交官、王族与各物种精英；Brunis凭特殊经历获得机会后成为所属学科最高分学生。

#### 17. Varro’s University

阿达斯特拉最高声望大学，位于首都外森林，拥有大理石柱廊、雕像、花园、宿舍、公共浴池、地下棋室和受限馆藏。它借鉴奥莫法教育，却仍以狼族精英为中心。女性约在近五十年才被允许与男性在主楼共同上课。校规严禁校内一切性活动，学生因此使用城内商业den。

#### 18. Den

首都提供付费私密房间的商业场所，尤其服务受大学禁欲校规约束的学生。高档房间有人工compluvium光顶、登记系统、走廊和完整床铺。Den不是洞穴，也不等同普通住宅。

#### 19. Lover’s Day

狼族庆祝所爱与珍视者的节日。核心是与重要之人共同度过一天，并不以交换礼物为主。鲜花、下跪、戒指等来自人类的习惯只在个别关系中被引入，并非全月球统一传统。

#### 20. Virdi

以类似黄瓜的果实汁为主的冰冷非酒精饮料，通常呈绿色，粉红变体可带明显花香。它清凉、带蔬菜味，是宫廷野餐、别墅储藏和日常餐饮中的常见饮品。

#### 21. Oliban

阿达斯特拉与Lux家庭空间使用的一种香气或熏香类型。它能成为强烈的家庭记忆标记，但其植物、化学构成和宗教用途没有确定说明。

#### 22. Dakhet en-Shemau

克米亚极辣禽肉菜。中心肉块热辣到近似“熔化”，周围配食可缓和刺激；Ahm能按个人健康档案调整辣度。它体现克米亚对辛香和强烈味觉的偏好。

#### 23. Nettek aum hotep akh

克米亚亲密迎接语，大意为“欢迎并安心吧，兄弟”。“兄弟”既可指血亲，也可授予极亲密的朋友。语言中的细微语序和情感重量难由Lingua完全保留。

#### 24. Meera与“完成Meera的工作”

Meera是来自Hindo的虎族女性，约一万年前以自身牺牲影响Drusus，使狼族重新联系Parents并建立Adastra。狼族把此事改编成舞剧和国家神话，常把Drusus塑造成主动拯救者。Parents所说“完成Meera的工作”，指再次由外来sapient把狼族从自毁道路拉回银河合作，而不是简单重演浪漫传奇。

#### 25. Time of Matr与Pre-Adastra

Drusus命名Adastra之前的前建国时代。其政治比后一万年更加分裂，史料脉络不完整。Time of Matr是时代名称，不是单一王朝；现存历史不足以证明当时各地拥有后世统一帝国式的相同制度。

### 五、天体、地域与生态术语

#### 1. Stella Vita与Vita

阿达斯特拉所在恒星系的恒星。Stella Vita是完整称呼，Vita是当地日轮或恒星的常用短称。它不是阿达斯特拉本身，也不能仅凭祝祷语把它定义为特定太阳神。Lux与首都存在数小时级地方时差，Vita升起的时刻因地区而异。

#### 2. Ancoris

阿达斯特拉环绕的高重力行星。其大气不可呼吸，裸身无法生存；被放逐的狼只能居住在密封基地，穿特制太空服外出采矿。强重力会造成骨骼变形、肌肉撕裂、器官和心血管损伤，即使返回阿达斯特拉也可能留下永久后果。Ancoris是行星，不是阿达斯特拉的另一地区。

#### 3. Adastra

环绕Ancoris运行的可居住卫星，也是狼族月球级帝国的国名。它有十九小时昼夜、至少一片大陆、多座主要城市、山地、森林、湖泊、南方somni产区和可供大型生态系统生存的大气。将其称为“世界”是政治或日常表达，天文学分类仍是moon。

#### 4. Torque

Ancoris的另一颗较小卫星，从太空看近乎纯白。它与绿蓝色Adastra、粉笔灰Ancoris共同构成抵达Stella Vita系统时最醒目的天体组合。其地表、生态和居民情况没有公开定义。

#### 5. Adastra City

帝国首都，位于皇宫湖对岸及周边地区。核心区有高耸、闪亮的玻璃或晶体感建筑、巨幅屏幕、飞行器航灯和较稀疏的街道人流。城市人口曾超过五百万，是权贵、官员、皇室媒体与高端技术最集中的地方；约三百万是主要城市的平均尺度，两项数字对应不同统计范围，并非同一个恒定人口值。

#### 6. Imperial Palace与皇宫湖

首都权力中心，拥有机库、王座厅、皇家露天剧场、档案球、花园、浴场、地牢、私人套房和大湖。建筑以大理石地面、柱列、拱门、石雕与隐藏感应门为主，高端自动化与古典帝国审美并存。湖中有树木繁茂的小岛，岛上通讯覆盖较弱，曾被用作秘密通信点。

#### 7. Imperial District、Silk District与Clay District

Imperial District是首都权贵和外交客居住区，住房法规可被地方官员用于排挤外族。Silk District提供较高等级短租住处。Clay District是最贫困、反精英情绪最强的城区，分离主义活动和街头暴力风险较高。三者是首都城区，不是独立城市。

#### 8. Lux

阿达斯特拉远北山地资源城，又称City of Defiance或City of Rebellion。它被雪山、丘陵、巨石和褐色低矮植物环绕，城内灰冷、贫穷、实行严格宵禁并保留公开鞭刑。Lux是全月球最大的天然资源与制造业中心，居民贫困来自财富截留、腐败与交通隔绝，而非土地没有价值。

城外天然硫泉清澈、丝滑而灼热，被认为有疗愈和催情作用；确定效果仅包括温热舒缓及令毛发柔顺。Lux曾是独立城邦，矿工罢工足以中断全月球工业，中央监管常引发暴乱并最终迫使皇权退让。

#### 9. Lupas

阿达斯特拉文化中心和第二富城市，人口约一百五十万，低于约三百万的城市平均值。它在五千多年前曾短暂担任不到十年的首都，现由少数富裕家族实际控制triumvirate。Lupas要求更高投票权和对中央决策的否决权，分离主义、反女性执政与狼族至上邪教均很活跃，历史上还存在刺杀政治关键人物的传统。

#### 10. Ad Rotae

阿达斯特拉最富有的娱乐、度假和演出城市。它有大型舞台、丰富餐饮、带安全争议的巨型游乐设施和皇室别墅，整体呈现炫目、消费密集的娱乐都会气质。它不是工业资源中心。

#### 11. Tricelli

承担Lux资源精炼和向其他城市分配的交通节点。Lux货物以人力和马车送到河流，再由货船运抵Tricelli；河运不载普通旅客。Tricelli曾在历史上较长、较晚地担任临时首都。

#### 12. Gebii与Lex

Gebii是参与帝位Trial投票的主要城市之一，目前公开细节很少。Lex是经济状况较好的另一座城市，与资源困顿的Lux并非同一地点。二者的气候、产业与建筑风格仍未明确。

#### 13. Varro森林与Simiarbor

Varro与首都之间的森林有古老扭曲树干、浓密灌木、巨大蛛网和夜间枝叶异响。Simiarbor是当地传说中的黑色灵长类隐兽，据说脸长在头颅反面，红眼会从树上凝视行人。可靠目击不足；它可能只是民俗、误认或The Other投影，不能列为已确认物种。

#### 14. Khemia

面积约为Adastra十二倍的可居住行星，也是十五个物种共同构成的文明与国名；jackals占总人口六成以上。从轨道看呈米黄色沙漠球体，大气尘埃明显，地表布满人工线条、设施和改造痕迹。赤道极热干燥，原始生态以地下昆虫和矮小耐旱植物为主；两极融水带孕育古代水王国。后世terraforming使原本难以居住的环赤道地区也能承载文明。

#### 15. Khemen

克米亚首都。王宫坐落于此，但高墙与安保限制使外来使团落地时无法完整看见城市。已知王宫外观强调直线、锐角、彩绘和凹刻象形文字；任何关于普通街区、市场和居民区的完整面貌都不能由宫殿风格直接代替。

#### 16. Aarum

前Galaxias时代最强大的克米亚水王国及历史名城。其古建筑和纪念物比Khemen王宫更加壮观。它代表克米亚统一前围绕极区融水发展的政治传统，不等同现代首都。

#### 17. Amadun

克米亚王室成员Henut接受训练的地点。训练内容、地点性质和是否与继承直接相连均未公开；Amadun目前只能确定为一处敏感地名，无法据此判定设施性质或具体职能。

#### 18. Water kingdoms

克米亚统一前围绕两极融冰水源形成的古国体系。水是农业、城市和权力的根本，古国之间长期因水开战；在当时，从一个极地文明跨越赤道抵达另一个极地文明，困难近似后世星际旅行。

#### 19. Deshereth与Quarto-2413b

克米亚记录中的狼獾母星名为Deshereth；阿达斯特拉官方目录称相关目标为Quarto-2413b，距Adastra约五十七光年。两名高度对应同一场探索权交易、狼獾uplift、大屠杀和第三次克米扬战争，但没有权威定义直接宣布二名完全等同，因此仍作为并行名称存在。

Deshereth的狼獾原居地下，提升后已发展住宅、学校与育儿设施。阿达斯特拉突袭造成超过五百名克米扬和十三万五千名狼獾死亡，数月后只找到两名狼獾幸存者。突袭前的Deshereth已经形成稳定文明，绝非只有矿产价值的荒星。

#### 20. Omorfa

与猫族文明相连的Sibling世界或政治共同体，具高度植物技术、医学声誉和接近Parent层级的科技。奥莫法与阿达斯特拉有至少三次战争，后又以“Chaos”战略渗透狼族宫廷，试图令其长期内耗。奥莫法社会正经历约千年来首次严重政治动荡，反Parent思潮明显，但“全体猫族已形成统一反Parent国策”仍不能视为定案。

#### 21. Hindo

包含虎族在内的Sibling文明。Meera来自Hindo，远古时期曾帮助Parents约束狼族。Hindo保留跨位面的古老仪式传统；当代已与阿达斯特拉完全断交。不能据虎族代表人物推断当地只有虎一种物种。

#### 22. Taharka

以狮族为重要成员的先进Sibling文明，与克米亚关系紧密，对应Parent为Kushari。其跨位面职位称dakhur。塔哈尔卡被视为银河第二先进的Sibling，并曾介入阿达斯特拉—克米亚战争。

#### 23. Earth与Rome

地球是多种Sibling文化被有意置入同一物种的实验性微缩世界。人类在没有保留Galaxias共同知识的情况下自行发展出核能、航天、互联网和现代国家体系，已达到类似Sibling的自主层级，不应成为任何Sibling的Child或殖民地。Rome保存Roman Forum等Romanus介入痕迹，也是Marco被带离和返回地球的关键地点。地球灯光密度、人口与国家数量远高于衰退期阿达斯特拉的单城格局。

#### 24. Simia与Simanian

Amicus为掩饰Marco来历而使用的虚构或不可靠身份体系，将其说成来自Simia的Simanian。该称呼不能当作已确认星球与物种；它首先是宫廷掩护身份。

### 六、物种与身体称谓

#### 1. Wolves／Wolven／Adastrans

狼族是Romanus选中的Sibling物种，也是阿达斯特拉帝国主体。成年雄性常接近七英尺，厚毛、口鼻、尾、可动耳、爪、肉垫和强健犬齿明显，力量、听觉、嗅觉、夜视与耐伤普遍强于人类。高温时以喘气散热，厚毛使其更耐Lux寒冷，却在Khemia干热中容易过热。狼族天生或文化上普遍会游泳，幼年甚至会绕皇宫湖岛竞速；传统泳姿以强力扑跃式划水，速度快却效率较低，人类自由泳可被狼迅速学会并显著提速。竞技游泳者还会把毛剃短以减少阻力。

颈部鬃毛可经家族长期培育并编辫，成为阶级标志。狼族法律成年年龄为二十个本地年。现有补充剂可显著延长寿命，但天然寿命与所有个体的统一寿命上限没有精确常数。

#### 2. Humans

地球本土灵长类sapient。人类无全身皮毛，依赖出汗散热，赤足易被热沙灼伤，寒地和强日晒中需要衣物防护；多数人比狼、熊和狼獾矮小脆弱，却发展出成熟游泳文化与高效自由泳技术。人类不是“半成品Child”，其文明在失联状态下已自行完成许多提升目标。其特殊医学风险包括对avia pox极端易感。

#### 3. Khemians与jackals

### 七、世界运行硬规则

#### 规则一：普通生命共享根源，但不同星球不是同一生态箱

银河这一侧的普通生命具有共同根源，因此不同天体会反复出现相似的哺乳类、鸟类、昆虫、蜘蛛、植物和智慧身体结构。相似性允许跨物种食物、药物、语言植入和医学有一定兼容基础，却不保证完全兼容。阿达斯特拉蜘蛛不等于地球蜘蛛，胡狼不等于狼，人类对avia pox的反常反应也证明微小差异足以造成致命后果。

共同根源只保证“趋同而非复制”：不同天体可以存在相似气味、形态和生态位，却不会自动共享毒性、繁殖期、寿命和食性。

#### 规则二：世界没有被确认的传统魔法，超常现象来自高层位面、心智或极端技术

隔空阻止攻击、时间停滞感、死者显现、远距意识接触、身体重构与未来视野均真实存在，但它们分别属于Parent干预、Monitor桥接、gift、Archive、Stretch层间效应或The Other投射。法术、法力、元素魔法、可任意施放的治疗术等体系没有既定位置。

已知超常效果都有相应通道：Parent授权、Monitor接入、Archive、Stretch、somni、veil thinner、gift或异质意识。没有通道时，普通sapient仍受重力、创伤、缺氧、疾病、温度和交通时间约束。

#### 规则三：Parents强大但不全知、不全能

Parents能从侧面观察时间，看到大量threads与possibilities，以概率评估路径并重新分配观察等级。它们会预测失败；干预越多，后续越难看清。提前向关键人物透露信息也会改变行为，使原有未来模型变得模糊。

因此，Parent预见是带条件的路径，不是已经发生的历史。它们可以保证“若完全遵守指令便抵达某条未来”，却不能把所有偏差自动消除。多个Parent心智呈现高度相似、基本一致的长远意图；现有接触只显示它们对具体干预尺度可能存在差异，不足以据此划分彼此敌对的派系。Monitor可以质疑其伦理与能力，却仍忠于共同计划。

#### 规则四：时间视野不等于时间旅行

高层心智能把时间作为整体观察，凡人也可在短暂主观时间内体验数百年条件性人生；这不表示肉身可自由回到过去、修改已发生事件。意识会谈期间，物理时间可能近乎停止、跳过一段或留下记忆空白，但每次表现都依赖高层机制，普通sapient无法随意调用。

未来信息天然分为已发生事实、当前计划、概率路径、梦境预示与条件性未来。五者处于不同确定层级，只有第一类属于既成编年。

#### 规则五：Monitor是桥梁，不是全能任务发放者

Monitor可以观察、读心、构建共享意识空间、转达Parents的限制和命令，也能在许可范围内提供线索。它不能独立决定Parents全部计划，不能保证每位关键人物安全，不能在现实中直接用精神场域伤害身体，也不能随意透露被Parents封锁的内容。

Monitor拥有独立人格，所以其同情、讽刺和愤怒是真实态度；但态度不改变它作为计划执行者的结构性服从。它的善意不自动证明Parents的选择公正。

#### 规则六：Agency始终存在，但可能被权力塑造成强迫选择

关键人物能拒绝Parent任务、讨价还价、要求提前知情或选择留在异星。与此同时，Parents可把回乡、爱人、文明存亡和技术支持放在选择两端，使形式自由伴随巨大胁迫。Agency并不表示任何愿望都会被尊重，而是即使力量不对等，sapient仍能作出改变路径的决定并迫使高层重新计算。

The Leaves同样不能靠纯强制完成控制，必须让对象真正产生want。这使承认欲望、保持拒绝和建立人际锚点成为对抗它的硬机制，而不只是心理安慰。

#### 规则七：Stretch受能量、载具、授权与路线约束

Stretch不是瞬移。飞船仍需起飞、离开重力井、进入驱动、退出、接近目标、再入和着陆；舱内有空气、水量、食物、运动病与机械故障。航程可从数小时到更久，因船型、窗口、能量和路线不同而变。Khemian驱动更快，不能用阿达斯特拉旧船耗时套在所有航线。

Lingua会把时间、距离和词义自动换成宿主易懂形式。不同文明所说的“小时”“年”可能已经经过概念换算。它对完整句子越熟悉越自然，对专名、歌唱、双关、发音失败和从未录入的概念越不可靠。

因此，数字能够标示顺序和大致尺度，却无法在缺少当地历法时自动形成精确公历。绕过Lingua而直接使用对方语言，会显露真实口音、节奏与情感，也可能因发音不清而让双方完全听不懂。

#### 规则九：人工系统很强，但不是已确认的sapient

Com与Ahm能像人一样对话、分析和提问，却仍受权限、输入、政策和优化目标控制。它们会遗漏警告、误解习语、执行不道德命令或在施暴后只派清洁无人机。它们不会凭空获得无限创造力，也不会自然越过皇室或国家权限，更不自动拥有道德良知。

#### 规则十：Parent医疗有窗口、有权限，也有物种差异

机械视觉、合成声带、身体重构和意识抽回都需要特定设备或Parent介入。死亡不久且心智仍可回收的人可能被救回；彻底融合、时间过长或没有接口者没有普遍复活保证。普通医师、无人机和药片不能复制Archive级奇迹。

#### 规则十一：死亡后的意识总体真实可接触，伦理解释仍未定案

Marco在死亡后进入巨大融合意识，又被Archive与Parent级机制触及并抽回，这些现象足以支持Amalgamation并非纯粹寓言。死者能否普遍拒绝融合、长期保留完整人格并在plane交界显现仍未证实；“融合是否幸福”“个体是否永远保留”“The Other是否能污染其中”也没有统一答案。

普通狼会把Greater Intelligence当确定归宿；Khemian宗教和sakhaet传统拥有不同理解；一名自称Meera、并声称拒绝融合的意识与Monitor说法冲突。各文明、阶层与个体依其经历和知识权限持有不同立场，并不共享一个终极答案。

Gift允许意识跨plane移动，与同类gifted者建立远距联系，并感知Parents；它不让使用者随意阅读所有人思想、准确预测单一未来或控制身体。稳定接触通常需要bond、key、gate和grounding。普通心智屏障会阻止侵入，过深接触还可能造成疼痛、昏厥和外来意识袭击。

The Other投影取自宿主能想象、害怕或渴望的形象，可模仿熟人、死者和神祇，说出对方认为“可能说”的话。外形本身不足以识别它；声音异变、逻辑诱导、对恐惧和want的精准利用，以及切断关系与生命意义的企图，构成更稳定的共同特征。

弱残余通常无法直接伤害现实身体，强项是诱导反应、混淆真假和放大疑虑。由它显现的内容可能掺入真实记忆，却不能仅因“说中了秘密”便视作该人格本人。

Sibling、Child、abandoned Child和pet描述权力关系与历史位置，不是脑力分数。被uplift的狼獾可以成为顶尖外交官；失联人类能自行发展出先进科技；最弱的Sibling仍可能压制Children；最先进文明也会陷入政治动荡。

阿达斯特拉有Archive、Stretch、致命无人机和隐形飞船，却让普通Lux居民依靠步行、马车和单一河运；皇宫几乎全自动，农村与小省份仍缺医疗、教育和快速交通。先进技术被皇室、Parent授权和城市中心垄断，不能据皇宫设备推定全月球生活水平。

首都湿热、权贵集中；Lux寒冷、资源丰富却被剥夺；Lupas富裕、文化强势且寡头化；Ad Rotae以娱乐和消费为核心；Tricelli承担资源精炼。这些地域差异直接决定当地常见衣物、政治风险、交通方式、口音印象与待客礼仪。

胡狼王室在政治上显眼，却不能代表全部人口。克米亚由十五个物种构成，jackals占总人口六成以上；Brunis确认狼獾可拥有Khemian公民身份。约二十万Omorfan居民是否计入这十五个物种并未说明。Khemian礼仪、法律和教育可以跨物种共享；耐热、嗅觉、游泳和毛发则随身体种类不同。

Parents能观察巨大时间结构、计算路径腐化和改变关键节点，但其知识会被干预、提前泄密和sapient选择扰动。它们并非不知道一切之后故意装作不知；预测失败和低概率路径是真实限制。它们也没有公开解释The Other最终物理机制、Amalgamation全部主观状态与银河统一的每一步方法。

#### 7. The Other所说内容的边界

The Other能读取并重组宿主心智，因此它说出私人秘密、真实恐惧或合理历史，不等于其自称身份真实。它最有效的谎言会混入真相，使对象相信只有它愿意诚实。“所有生命都该消失”“任何关系必然背叛”“融合只有无尽痛苦”等绝对结论，本身就是其操纵目标的一部分。

#### 8. 秘密事项的认知范围

普通公民无从得知以下事项：Pharaoh当前下落；Amadun训练内容；Ahm是否真正sapient；Children of Sahira最近机密行动；The Leaves与The Other是否同一；Deshereth与Quarto-2413b的官方同名确认；奥莫法、Hindo、Lupas资金和克米亚王室异动是否属于同一阴谋；Lux危机当日未公开的收束经过；Khemen普通街区全貌。

### 九、常见误判纠正规则

1. **阿达斯特拉是卫星，不是行星。** 它环绕Ancoris；Torque是同一行星的另一颗卫星。

2. **克米亚是行星，也是多物种国家。** “Khemian”不等于“胡狼”，如同“Adastran”在政治语境中也不必只描述生物分类。

3. **Sibling、Child与pet都不是智力等级。** 它们首先定义文明关系、提升历史和法律权力。Child可以比Sibling个体更聪明、更有学识；pet也可以是完整外交主体。

4. **人类不是传统Child。** 地球经历多文明介入后失联，又自行发展，现被归入类似Sibling的独立层级；任何Sibling都无权占有地球。

5. **Parents不是无所不能的神。** 它们的技术和时间视野近似神迹，却会预测失败、依赖Monitor，也会因自身干预造成未来模糊；已知差异只涉及具体干预尺度，不足以证明存在彼此敌对的内部派系。

6. **Monitor不是Parent。** 它是被设计出来的桥梁，有人格、有权限上限，也会被Parents拒绝提供答案。

7. **Parents的条件性未来不是既成历史。** 八年后重聚、百年内帝制退出、数百年寿命均属于依赖特定选择的未来路径，尚未成为当代事实。

8. **Stretch不是跨银河航行。** 它能跨恒星和银河内部远距旅行；真正的intergalactic travel仍是Sibling晋升Parent的技术门槛。

9. **Stretch不是瞬移。** 起飞、进出驱动、目标接近、再入、能量和生理负担都真实存在，航时也不固定。

10. **Plane不是普通空间楼层。** “上方”“中间”“边界变薄”是心智理解高层存在的方式；它们没有可供常规推进器导航抵达的物理坐标。

11. **Archive不是普通图书馆。** 它是蓝色球形脑机、档案系统与Parent通信终端，也能触及死者意识。

12. **Greater Intelligence与Amalgamation不是Parents。** 前者是死亡后意识总体，后者是否由Parents创造、管理或仅被利用仍没有完整答案。

13. **未融合灵体不等于所有鬼故事为真。** 呈现Meera形态的显现、The Other投影、somni幻觉和地方传说来源各异，外观相似不足以证明性质相同。

14. **The Leaves尚未正式等同The Other。** 二者特征高度重合，但现有知识体系仍保留两个称谓和一条未完成的关系判断。

15. **The Other不是会随处肉搏的普通怪物。** 弱残余主要寄生心智、借反应增强；它最危险的武器是可信的熟人形象、真伪混杂的话语和对欲望的利用。

16. **Gift不是万能读心。** 使用者通常只能稳定接触同样具gift、亲自认识并建立bond的人，普通心智存在屏障。

17. **Ahewawi不是超能力，也不是疯狂的同义词。** 它是“旧痛”，可治疗和管理；gifted者必须另行筛查精神状态。

18. **Somni不是可靠的Parent电话。** 大多数体验为致幻；只有Monitor主动利用时，才可能成为真实共享接触的入口。

19. **Lingua不是无损语言。** 它会覆盖原声、意会单位、漏掉歌唱与专名；不同使用者即使“听懂”也可能错失口音、双关和文化重量。

20. **Com与Ahm没有被确认具有意识。** 语言自然、服务细致或好奇提问都不足以判定sapient；它们仍依赖权限和国家系统。

21. **高端无人机不代表全民富裕。** 阿达斯特拉皇室拥有能使目标呈波形扭曲并爆裂的未明致命武器，Lux普通居民却可能连离开山区的飞行费用都负担不起。

25. **Avia pox对人类的危险不能按其他灵长类估计。** 除 Parent 直接重构这一特殊干预外，人类病例呈极快发病且已知全部死亡，Marco还可能无症状排毒。

26. **Khemian pap不是somni，也不是无害饮料。** 它是chronoma品系，有医疗用途、个体差异和成瘾风险；阿达斯特拉的非法化宣传与克米亚的受控供应都只描述制度的一部分。

27. **Pet不是宠物动物的温和习俗。** 对智慧个体而言，它包含跪地服侍、剩食、契约、转让与政治展示，是明确的支配关系。

28. **阿达斯特拉的政治不是纯绝对皇权。** 皇帝权力极大，但地方triumvirates、城市选票、Trials、Senate、媒体和荣誉决斗都能形成实质约束。

29. **克米亚也不是没有约束的神权王朝。** 公民依法可批评pharaoh，私人空间受隐私法保护，外交人员有豁免；vizier违法越权不等于法律允许。

### 十、五感速查

#### 1. 抵达Stella Vita系统

- **视觉**：绿蓝色Adastra浮在粉笔灰的Ancoris旁，更小的Torque近乎纯白；近恒星时窗外出现电蓝光和变暗的防护层。
- **听觉**：飞船内部持续低沉机械嗡鸣，控制台发出蜂鸣和啁啾提示；再入时座椅轻震，声音不一定如旧式火箭般震耳。
- **嗅觉**：老旧船舱与机械空间可有闷滞气味；靠近某些飞船时曾出现燃烧橡胶般气息。
- **触觉**：安全带自动收紧，舷窗冰冷；强引力或错误航向会把未固定者猛甩向舱壁。
- **情绪基调**：高科技并不洁净神圣，而是古旧、权限混乱、带故障风险的Parent遗产。

#### 2. Stretch航行

- **视觉**：星光从前方被拉成长线，向两侧和后方弯折；直视越久越容易失衡。
- **听觉**：舱内仍是机械低鸣与空气循环，超常接触未必伴随外部巨响。
- **嗅觉**：克米扬飞船循环空气略带陈旧金属味；烟雾会被过滤系统迅速抽走。
- **触觉**：起飞加速感可极弱，运动病却很强；意识进入层间状态时可能感到身体拉长、坠落、被向上扯走或突然失去重量。
- **心理感受**：时间与空间的直觉变得不可信，梦、记忆、死者与外来声音比平时更容易侵入。

#### 3. 阿达斯特拉皇宫外部

- **视觉**：大理石、柱列、拱门、雕像和明亮顶灯从机库延向庭园；清晨粉橙色光照亮云层，湖两岸是浓绿山丘与远山，对岸首都高楼窗光闪烁。
- **听觉**：夜间石廊脚步回响，机库外有类蟋蟀鸣声，清晨有近似地球的鸟鸣；飞行器以蓝红航灯掠过湖对岸。
- **嗅觉**：夜间空气湿热如桑拿，清晨则有清新湖水与夏令营般草木气息；狼身常带薰衣草、花香护理液和被香液压住的浓厚体味。
- **触觉**：高湿令毛发潮湿，阳光很快变得灼热；室内冷风与公共区偏暖温控形成明显落差。
- **情绪基调**：古典权力与隐藏自动化共存，空间壮阔，却因常住sapient极少而显得安静、空旷。

#### 4. 皇宫室内与私人房间

- **视觉**：光滑石门像整块大理石，触碰黑色方板后无声滑开；照明随人进入渐亮。卧室有宽床、红沙发、阳台、浴室与简洁陈设。
- **听觉**：门、餐盘和服务无人机大多安静，Com的声音可从环境中直接响起；石材让脚步和争吵传得更清楚。
- **嗅觉**：洗浴区混合热水、毛发护理油、薰衣草液与湿毛味；矿物浴带硫与石质潮气。
- **触觉**：自动淋浴进人即启动，墙面色谱调温，结束后强风吹干厚毛；石质厕所与长凳偏凉，浴场水温偏高。
- **情绪基调**：生活便利高度依赖权限；同一扇门对普通人、pet、顾问和皇帝有完全不同的服从程度。

#### 5. 皇宫花园

- **视觉**：藤蔓、灌木、白色小花、乔木、池塘和树荫长椅围绕柱廊；类蟹蜘蛛张腿宽如钟面，黑色小眼密集，能迅速攀墙或爬上身体。
- **听觉**：鸟鸣、叶片摩擦、无人机轻微运作声与水池声构成背景；大蜘蛛移动未必发出与体型相称的声音。
- **嗅觉**：近距离最明确的气味来自狼族身上的薰衣草与花香护理液。
- **触觉**：小杂草仍会从石缝和花圃中冒出；蛛咬最多留下发痒肿块，突如其来的多足爬动会制造强烈触觉恐惧。
- **情绪基调**：不是消毒后的王宫装饰园，而是由无人机维护、仍保留完整节肢动物生态的活花园。

#### 6. 皇宫湖与小岛

- **视觉**：湖面远看宁静，略有波浪；岛正面是浅色沙滩，背面树木与植被浓密到几乎无滩。夜里湖映月光，岛只剩黑色轮廓，巨树叶片泛银。
- **听觉**：水拍湿沙、风过树冠、远处城市低响；岛上Com覆盖消失后，环境突然少了人工声音。
- **嗅觉**：临湖清晨空气清新，使Marco联想到夏令营时的湖畔露营。
- **触觉**：湖水冰冷，浅水下沙会流动；烈日把干沙晒得足以灼伤人类赤足，湿沙和浪水则迅速降温。水深与距离足以让久未锻炼者力竭。
- **情绪基调**：白昼像私密度假地，夜晚则因通讯盲区、密林和秘密植物设备转为隔绝与不安。

#### 7. Adastra City

- **视觉**：湖对岸高大核心建筑向两侧渐矮，表面像玻璃或晶体般闪亮；巨幅屏幕与新闻画面占据公共视线，街区在宵禁或皇帝清场时会异常空。
- **听觉**：演说、新闻和Trial可通过公共频道覆盖全城；暴乱时远处人群、破坏声与飞行无人机混成持续噪音。
- **嗅觉**：临水区域带有湿润的湖畔空气；骚乱期间，局部城区会短暂出现火灾烟气。
- **触觉**：夏季空气黏在皮毛与皮肤上，深夜和冷季湖边更舒适；城市步行距离并不总长，贵族乘马车常为身份而非必要。
- **情绪基调**：首都同时是权力舞台、媒体机器与阶级滤镜；同一街区能因皇帝指令从繁华变成空城。

#### 8. Varro’s University与森林

- **视觉**：浅色大理石走廊、宏大主楼、狼族雕像、整齐花园与柱廊构成古典校园；地下有棋盘游戏室，公共浴池和宿舍分布其间。森林中树干古老扭曲，巨蛛网可横跨十英尺。
- **听觉**：讲堂与浴池人声在石面回荡，森林夜间有枝叶异响和看不见的移动；在The Other影响下，普通环境声会被解释成耳语或枯叶摩擦。
- **嗅觉**：公共浴池有天然硫味；somni燃烧时则带樟脑丸般的刺鼻化学气味。
- **触觉**：大理石长凳和走廊偏冷，公共浴水温热；somni会带来咳嗽、呕吐、震颤、血眼和空间被拉伸的眩晕。
- **情绪基调**：学术开放与知识禁区并存；美丽雕像、受限书库、阶级鬃毛和暴乱旧伤让校园始终带压抑历史。

#### 9. 皇宫地牢

- **视觉**：入口藏在小室地坑，经梯子下降；内部是昏黄照明、石墙、石地、狭窄牢房和沉重阴影。
- **听觉**：地面广播传不下来，脚步、铁门和Com计时声在走廊回响；安静会放大呼吸与衣料摩擦。
- **嗅觉**：空气冷、潮、霉、陈旧，长期缺乏流动。
- **触觉**：石面冰冷，湿气渗进皮毛和衣物；被关押者数日后会显得消瘦、失去日常护理香味。
- **情绪基调**：它不是公开司法场所，而是由皇帝权限、囚籍和访问时限严密控制的权力盲区。
