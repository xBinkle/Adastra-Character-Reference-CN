# 《Adastra》系列角色设定与世界观参考库

> 非官方、非商业的中文同人研究与沉浸式角色参考项目。

本仓库对《Adastra》系列三部作品——《Adastra》《Interea》《Khemia》——进行系统化文本精读、跨作品考据、人物行为分析与世界观整理。项目目标是尽可能保存角色在原作中的经历、关系、语言习惯、心理逻辑和外貌特征，并为非商业研究、同人创作及沉浸式角色扮演提供结构化参考。

## 阅读前须知

- 仓库包含三部作品的大量完整剧透。
- 原作及部分文本涉及成人主题，仅适合达到当地法定年龄的读者。
- 本项目不是 Echo Project 或原作者发布、审核或认可的官方资料。
- `source-data` 保存了用于研究的剧情提取数据，不能替代购买、下载或体验原作。
- 文档中的事实整理、文本推断和角色建模应结合上下文理解；未标明说话人的语句可能包含基于剧情语境作出的身份判断。
